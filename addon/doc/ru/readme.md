# Документация по Vision Assistant Pro

<!-- DOWNLOAD_COUNT_START --> Всего загрузок: 62 863 <!-- DOWNLOAD_COUNT_END -->

**Vision Assistant Pro** — это продвинутый мультимодальный ИИ-ассистент для NVDA. Он использует ИИ-движки мирового класса для интеллектуального чтения экрана, перевода, голосовой диктовки и анализа документов.

_Это дополнение было выпущено для сообщества в честь Международного дня инвалидов._

## 1. Настройка и конфигурация

Перейдите в **Меню NVDA > Параметры > Настройки > Vision Assistant Pro**. Диалог настроек организован в 9 доступных вкладок: **Подключение**, **Живой помощник**, **Поведение ИИ**, **Языки перевода**, **Чтение документов**, **Видео**, **CAPTCHA**, **Запросы** и **Дополнительно**.

### 1.1 Вкладка «Подключение»

- **Провайдер:** Выберите предпочитаемый ИИ-сервис. Поддерживаемые провайдеры: **Google Gemini**, **OpenAI**, **Mistral AI**, **Groq**, **MiniMax** и **Пользовательский** (OpenAI-совместимые серверы, такие как Ollama, LM Studio, Jan.ai или KoboldCPP).
- **Ключ API (несколько ключей разделяйте запятыми или переносом строки):** Введите один или несколько API-ключей (разделённых запятыми или переносами строк) для автоматической ротации.
- **Загрузить модели:** Нажмите эту кнопку после ввода API-ключа, чтобы загрузить актуальный список доступных моделей от провайдера.
- **Модель ИИ:** Выберите основную модель, используемую для общего чата и анализа.
- **Advanced Model Routing (Task-specific):** Optionally select dedicated models from dropdowns for OCR, STT, TTS, AI Operator, Video, and Live Assistant tasks. For Gemini, models are dynamically categorized by capability without clutter.
- **Настройки пользовательского провайдера:** Настройте локальные или пользовательские эндпоинты. Включает **Настройка локального ИИ** (настройка в один клик для Ollama, LM Studio, Jan.ai или KoboldCPP) и **Расширенная конфигурация конечных точек**.
- **Proxy Configuration:** Full support for tunneling and endpoint redirection across the entire add-on (including the Live Assistant, Ambient Observer, and TTS). Enter your **Proxy URL** and select your **Proxy Mode**:
  - **Auto-detect:** Automatically detects whether the URL is a forward proxy or reverse proxy.
  - **SOCKS5 Proxy:** Forces forward tunneling via SOCKS5 with RFC 1929 username/password authentication and domain name resolution.
  - **HTTP Proxy:** Forces forward tunneling via an HTTP proxy with Basic authentication.
  - **Reverse Proxy:** Direct endpoint replacement for custom AI gateways and self-hosted mirrors (credentials are disabled in this mode).
- **Test Proxy Connection:** A non-blocking button that tests connectivity and measures server latency in milliseconds (spoken via NVDA).
- **Параметры подключения и вывода:** Настройте **URL прокси**, **Проверять обновления при запуске**, **Очищать Markdown в чате**, **Копировать ответы ИИ в буфер обмена** и **Прямой вывод (без окна чата)**.
- **Сохранять чаты в историю:** Сохранять ваши чаты в списке истории.

### 1.2 Вкладка «Живой помощник»

- **Живой помощник: прямой вывод (без окна):** Запускает Живого помощника без окна диалога; откройте его позже с помощью клавиши повтора последнего результата (`Пробел`).
- **Нажми и говори:** Переключить режим «нажми и говори». Когда он включён, ваш микрофон передаёт звук только пока вы удерживаете назначенную клавишу.
- **Клавиша «Нажми и говори»:** Нажмите клавиши, чтобы записать сочетание (например, `F12` или `Ctrl+F12`) — можно назначить даже одиночный модификатор, такой как `Left Ctrl`. Удерживайте клавишу, чтобы говорить, и отпустите, чтобы закончить; короткий звуковой сигнал подтверждает каждое нажатие и отпускание.

Примечание: Эта вкладка появляется только когда **Google Gemini** (или Gemini-совместимый пользовательский провайдер) является вашим активным провайдером.

### 1.3 Вкладка «Поведение ИИ»

- **Креативность (температура, не влияет на OCR/перевод):** Управляет случайностью и креативностью ИИ (от 0.0 до 2.0). Более низкие значения дают более детерминированные и точные результаты перевода/OCR.

### 1.4 Вкладка «Языки перевода»

- **Исходный язык:** Выберите ваш язык ввода по умолчанию.
- **Целевой язык:** Выберите ваш основной целевой язык перевода.
- **Язык ответов ИИ:** Выберите язык для общих ответов ИИ.
- **Умная замена:** Автоматически меняет местами исходный и целевой языки на основе обнаруженного ввода.

### 1.5 Вкладка «Чтение документов»

- **Движок OCR:** Выберите между **Chrome (быстрый)** для быстрых результатов или **ИИ (расширенный)** для превосходного сохранения макета.
- **Размер пакета OCR (страниц за запрос, 0 — отключить):** Укажите количество страниц на запрос (установите 0 для обработки одним запросом).
- **Описание изображений во время OCR документа:** Переключить встроенные описания изображений во время извлечения текста документа.
- **Включать номера страниц при экспорте документов:** Переключить номера страниц и разделители в выводах многостраничных документов.
- **Голос TTS:** Выберите стиль голоса по умолчанию для генерации аудио.
- **Сохранять документы в историю:** Сохранять открытые документы в списке истории; кэшированный текст OCR и данные возобновления всё равно сохраняются.

### 1.6 Вкладка «Видео»

- **Размер фрагмента видео для аудиоописания (минуты, 0 — отключить):** Длительность сегмента в минутах для генерации аудиоописания (установите 0 для обработки всего файла).
- **Добавить список персонажей как первый субтитр:** Опция добавления словаря персонажей в качестве первой записи субтитров.
- **Добавить отказ от ответственности ИИ в начале:** Опция вставки отказа от ответственности ИИ в начало SRT-субтитров видео.
- **Словарь персонажей и управление сериалами:** Добавляйте, редактируйте, импортируйте или управляйте именами персонажей, физическими описаниями и ролями по сериалам — ИИ автоматически сопоставляет обнаруженных персонажей с вашим словарём и объединяет новых по мере анализа дополнительных эпизодов. Ваши ручные заметки всегда сохраняются с приоритетом над обновлениями ИИ, а физические описания остаются актуальными во всех эпизодах.

### 1.7 Вкладка «CAPTCHA»

- **Включить решение визуальной CAPTCHA:** Переключить автоматическое решение визуальных задач (hCaptcha, reCAPTCHA).
- **Метод решения текстовой CAPTCHA:** Выберите между захватом **Объект навигатора** или **Весь экран**.

### 1.8 Вкладка «Запросы»

- **Управление запросами...:** Открывает специальный диалог для настройки системных запросов по умолчанию или создания, редактирования, переупорядочивания и предварительного просмотра пользовательских запросов с динамическими переменными (например, `[selection]`, `[screen_fg_obj]`).
- **Сочетания клавиш для пользовательских запросов:** Назначьте выделенную клавишу быстрого доступа любому пользовательскому запросу прямо в менеджере запросов. Нажмите клавиши, чтобы записать их — одиночные клавиши работают внутри командного слоя (и глобально как `NVDA + Shift + key`), а комбинации вроде `Control + Shift + 1` работают глобально самостоятельно.
- **Per-Prompt Feedback Behavior:** Choose how each prompt outputs its result individually (Global setting, Copy to clipboard, Direct Output / NVDA message, Copy to clipboard + Direct Output, or Chat window).

### 1.9 Вкладка «Дополнительно» и глобальное журналирование

Перейдите на вкладку **Дополнительно** для настройки глобального журналирования дополнения:

- **Включить отдельный файл журнала:** Переключает журналирование всех операционных событий, API-трафика и ошибок во всех модулях дополнения в отдельный файл (`vision_assistant.log`).
- **Уровень журналирования:** Выберите уровень детализации между **Отладка (все детали)**, **Информация (общие сведения)**, **Предупреждения (только предупреждения)** и **Ошибки (только ошибки)**.
- **Хранить журналы:** Установите периоды автоматического хранения для автоматической очистки старых записей журналов (от 1 часа до 90 дней).
- **Управление журналами:** Используйте **Открыть файл журнала**, **Открыть папку журнала** или **Очистить файл журнала** для просмотра или очистки данных журналов напрямую без перезапуска NVDA или вмешательства в стандартные журналы NVDA.
- **Единый каталог данных:** Все файлы данных дополнения (история, сериалы, метки, прогресс OCR, кэши и журналы) хранятся в единой папке `VisionAssistant` внутри каталога конфигурации NVDA — всё организовано и упрощает ручное резервное копирование.

### 1.10 Резервное копирование и восстановление настроек

Вкладка **Дополнительно** также включает раздел **Резервное копирование и восстановление**:

- **Резервная копия...:** Сохраняет вашу конфигурацию в один JSON-файл. При нажатии вы выбираете, что включить: **Всё (настройки, метки, прогресс OCR, история)** или **Только настройки**.
- **Восстановить...:** Загружает ранее сохранённую резервную копию для восстановления конфигурации и данных в любое время, на любой машине или после переустановки NVDA. Вас попросят подтвердить, так как восстановление заменяет все текущие настройки и данные.

## 2. Менеджер ключей API Gemini

Creating a Gemini API key on **aistudio.google.com** used to be the hardest step of the add-on. With a screen reader the pages were confusing, and some people simply could not create a key at all. The **Gemini API Key Manager** solves that problem. Press **G** in the Command Layer, or open **NVDA Menu > Preferences > Settings > Vision Assistant > Connection** and press **Get a Gemini API Key...**.

- **Signing in:** When you open the manager, your default browser opens directly with Google's secure sign-in page. Sign in with your Google account — no external tools, SDKs, or command-line setups are required. The account you are signed in with is always shown on the **Sign Out** button.
- **Creating a key:** After signing in, you can create a key immediately with **New Project and Key** without any prior setup. If you already have existing projects, they appear in a simple list where you can select one and press **Create Key for Selected Project**.
- **What happens next:** The new key is copied to the clipboard straight away, saved inside the add-on for later, and you are asked once whether to add it to the add-on's key list. That is all you need — no web pages to hunt through.
- **Working with your keys:** **Copy Key for Selected Project** copies the key of the project you have selected, **Copy Last Created Key** copies the key you created a moment ago, and **Export Saved Keys to CSV...** saves everything you have created to a file.
- **Deleting a key:** **Delete a Key...** shows the keys that exist on the selected project, asks you which one to remove, and confirms before deleting. Deleting a key also removes it from the add-on's key list, so no broken key is ever left in the rotation. Keys created outside the add-on can be deleted too, as long as your account has permission on that project.
- **Signing out:** **Sign Out** removes the stored sign-in information from your computer, so you can switch to another account whenever you like.

## 4. Чат и история

Окна чата и диалог истории работают во всех функциях, так что вы можете просматривать разговоры и продолжать с того места, где остановились.

### 3.1 Сочетания клавиш окна чата

Когда окно чата открыто (прямой чат, чат документа, обработка и подобные), вы можете просматривать разговор с помощью:

- **Alt + Down:** Прочитать следующее сообщение.
- **Alt + Up:** Прочитать предыдущее сообщение.
- **Alt + C:** Скопировать текущее сообщение.

### 3.2 История (Control + H)

Нажмите **Control + H** в командном слое, чтобы открыть диалог **История** с вашими прошлыми чатами и документами, фильтруемыми по типу (Все / Чаты / Документы). Откройте чат, чтобы продолжить разговор — включая его прикреплённые файлы, которые автоматически прикрепляются заново — или откройте документ и продолжайте чтение. Нажмите **Delete** на любом элементе, чтобы удалить его, или **Очистить всё**, чтобы очистить список. Для документов Delete спрашивает, хотите ли вы удалить только запись истории или также очистить кэшированный текст OCR этого документа, чтобы при следующем открытии он сканировался с нуля — с опцией **Больше не спрашивать**, чтобы запомнить ваш выбор.

Вы также можете выбрать, что помнит список. **Сохранять чаты в историю** (вкладка «Подключение») и **Сохранять документы в историю** (вкладка «Чтение документов») оба включены по умолчанию, и оба можно переключить в быстрых настройках. Опция документов влияет только на запись в истории — кэшированный текст OCR и данные возобновления всегда сохраняются.

## 5. ИИ-оператор — автономное управление компьютером

**ИИ-оператор** превращает Vision Assistant Pro из пассивного читателя в активного ассистента, который может взаимодействовать с вашим компьютером от вашего имени. Вы можете попросить его описать экран, ответить на вопросы о том, что он видит, или даже взять управление — нажимая кнопки, перетаскивая элементы, вводя текст и перемещаясь по приложениям с помощью команд на естественном языке.

Самое большое преимущество? Он отлично работает в полностью недоступном программном обеспечении. Если вы застряли в пользовательском приложении, удалённом рабочем столе или на веб-сайте, где ваш скринридер полностью молчит, оператору всё равно. Поскольку он «видит» экран визуально, он может находить, читать и взаимодействовать с элементами, у которых нет меток доступности.

### 4.1 Как это работает

1. Нажмите **NVDA + Shift + V**, затем **Shift + A** (или используйте прямое сочетание клавиш), чтобы открыть диалог ИИ-оператора.
2. Введите, что вы хотите сделать, простым языком (например, «Нажми кнопку Сохранить», «Что говорит сообщение об ошибке?» или «Переименуй файл в final.pdf»).
3. ИИ проанализирует ваш экран, идентифицирует соответствующие элементы и выполнит действие или предоставит ответ. Если задача требует нескольких шагов, оператор продолжит работу до её завершения.
4. Нажмите **Shift + A** снова в любое время, чтобы мгновенно прервать текущую операцию.

### 4.2 Поддерживаемые действия

Оператор понимает широкий спектр команд:

- **Описать и ответить**: «Опиши компоновку экрана» или «Что говорит сообщение об ошибке?»
- **Клик**: «Нажми кнопку Сохранить»
- **Правый клик**: «Кликни правой кнопкой по файлу»
- **Двойной клик**: «Дважды кликни по документу»
- **Перетаскивание**: «Перетащи документ в папку Архив»
- **Ввод текста**: «Введи 'Hello World' в поле поиска»
- **Прокрутка**: «Прокрути вниз три раза»
- **Нажатие клавиш**: «Нажми Enter», «Нажми Tab», «Нажми Escape»
- **Многошаговые задачи**: «Открой Проводник, найди отчёт и переименуй его в final.pdf»

### 4.3 Важные замечания

- **⚠️ Предупреждение об использовании API**: Поскольку оператору нужно «видеть» именно то, что происходит на экране, он отправляет скриншот высокого разрешения на каждом шаге. Частое использование будет расходовать вашу квоту API гораздо быстрее, чем стандартные текстовые функции.
- **Приложения с правами администратора**: Если NVDA не запущена с правами администратора, оператор может не иметь возможности взаимодействовать с окнами, требующими повышенных разрешений. Это ограничение безопасности Windows, а не ошибка в дополнении.
- **Лучшие практики**: Для лучших результатов давайте чёткие и конкретные команды. «Нажми синюю кнопку Отправить внизу формы» почти всегда сработает лучше, чем просто «Нажми кнопку».

### 4.4 Живой оператор (Control+A)

Живой помощник превращает Vision Assistant Pro в копилота реального времени, интерактивного.
_(Примечание: Эта функция эксклюзивна для Google Gemini и Gemini-совместимых пользовательских провайдеров)._

- Локальная запись экрана
- **How it works:** Ask in plain language, for example "open Chrome and search for a website" or "rename this file to final". The operator looks at the screen, carries out the steps one by one, and keeps working through multi-step requests until the task is done.
- **Announcements:** Every step is spoken in the Live Assistant's own voice, and it tells you when the task is finished, or why it could not be done.
- **CAPTCHA:** If a CAPTCHA appears, the operator tries your built-in **CAPTCHA solver** first; if it cannot solve it, it asks you to complete the accessible challenge yourself.
- **Stopping:** Press **Stop operator action** in the Live Assistant window to cancel the current task.
- **Settings:** The operator's own instruction can be edited in the Prompt Manager (section **Live**, **Live Operator Instruction**). The **Live Direct Output (No Window)** switch is available in Quick Settings as well.

## 6. Анализ видео и аудиоописание

> **Примечание:** Функции анализа видео и аудиоописания работают строго на провайдере **Google Gemini**. Убедитесь, что ваш активный провайдер в настройках дополнения установлен на Google Gemini.

Vision Assistant Pro представляет мощные возможности обработки видео, разработанные специально для незрячих пользователей. Он может анализировать как онлайн-видео, так и локальные записи экрана, чтобы предоставлять высокодетализированные визуальные описания и генерировать профессиональные сценарии аудиоописания (SRT).

### 5.1 Локальная запись экрана (Control + V)

Если вы столкнулись с беззвучным видео, анимацией или учебным пособием на вашем экране, вы можете записать его напрямую:

1. Нажмите **NVDA + Shift + V**, чтобы войти в командный слой, затем нажмите **Control + V**.
2. Дополнение будет беззвучно записывать ваш экран в фоновом режиме.
3. Нажмите **Control + V** снова, чтобы остановить запись.
4. Затем ИИ проанализирует записанный видеофрагмент и предоставит высокодетализированное описание сцены, персонажей и действий.

### 5.2 Анализ видео (Shift + V)

Вы можете анализировать как локальные видеофайлы, так и онлайн-видео. Просто выберите локальный видеофайл в Проводнике Windows или скопируйте ссылку на онлайн-видео в буфер обмена. Вы также можете нажать **Shift + V** в любом месте (например, внутри медиаплеера), чтобы открыть диалог, где можно выбрать видеофайл или вставить URL вручную.

- **Поддерживаемые онлайн-платформы:** YouTube, Instagram, TikTok и Twitter (X).
- ИИ автоматически обнаружит локальный файл или URL, обработает видео и предоставит комплексное визуальное описание и аудиорезюме.
- **48-часовое кэширование видеофайлов:** Видео, загруженные в Gemini, кэшируются на 48 часов! Вы можете повторно генерировать SRT или MP3-выводы для того же видео без повторной загрузки — даже после перезапуска NVDA. Кэш привязан к ключу и автоматически аннулируется при смене API-ключа.

### 5.3 Создание аудиоописания (SRT)

Для более структурированного опыта дополнение может генерировать профессиональные сценарии аудиоописания в стандартном формате SubRip (SRT).

- **Умное распределение по паузам:** ИИ слушает звуковую дорожку и специально привязывает свои визуальные описания к естественным паузам и тихим промежуткам, чтобы интеллектуально минимизировать перекрытие диалогов.
- **Отслеживание персонажей:** Движок выполняет предварительный проход для извлечения отдельных персонажей на основе неизменяемых черт лица. Он строит глобальный словарь для точного отслеживания и маркировки персонажей в разных сценах без путаницы. Он также отслеживает **первое появление** каждого персонажа, описывая их физический облик только один раз — в момент, когда они впервые появляются — и используя установленные имена только в более поздних сценах, чтобы сохранить повествование свежим и естественным.
- **Дословный OCR текста:** Любой текст, появляющийся на экране (вывески, телефоны, титры), строго цитируется дословно.
- **Как использовать:** Чтобы прослушать сгенерированный субтитр, просто поместите файл `.srt` в ту же папку, что и ваш видеофайл, и дайте ему точно такое же имя. Затем настройте ваш медиаплеер (например, VLC или PotPlayer) для передачи текста субтитров напрямую вашему скринридеру или TTS-движку во время воспроизведения.
- **Улучшенный опыт сохранения:** При сохранении SRT или MP3-файлов диалог файла теперь открывается в папке исходного видео по умолчанию, независимо от того, открыли ли вы видео через диалог файла или Shift+V из Проводника.

### 5.4 Синхронизированная аудиоозвучка (экспорт в MP3)

Помимо создания текстовых SRT-файлов, дополнение функционирует как полноценный инструмент производства аудиоописания, синтезируя описания в речь и смешивая их с видео. Теперь вы можете выбрать **Gemini Live TTS** в качестве голосового движка, который использует Gemini Live API для генерации высокореалистичного, неограниченного голосового повествования. При генерации MP3 для локальных видеофайлов у вас есть несколько режимов микширования:

- **Стандартное AD (наложение голоса на аудио — без пауз):** Повествование накладывается непосредственно поверх аудио видео. Вас спросят, хотите ли вы применить **понижение громкости фона** (понижение фоновой громкости во время описаний), чтобы обеспечить чёткость повествования.
- **Расширенное AD (пауза фонового аудио во время описаний):** Движок приостанавливает оригинальное аудио видео во время описаний, гарантируя, что вы не пропустите ни одного слова оригинального диалога или повествования ИИ. Обнаружение тишины теперь использует нейросетевую модель **Silero VAD** (загружается автоматически при первом использовании, как ffmpeg и eSpeak) для точного распределения по паузам — различая естественные паузы диалога от музыки и фонового шума.
- **Видео YouTube:** Для источников YouTube (которые не загружаются локально), экспорт MP3 будет строго содержать синхронизированную дорожку голоса ИИ без фонового аудио видео.

## 7. Транскрипция и дубляж медиа (M)

Аудиотранскрайбер был полностью переработан для поддержки как аудио-, так и видеофайлов (MP3, WAV, MP4, MKV и т.д.). Нажмите **M** в командном слое, чтобы выбрать медиафайл и выбрать один из 3 различных режимов работы:

1. **Транскрибировать (на исходном языке)**: Точно транскрибирует произнесённую речь на её оригинальном языке.
2. **Транскрибировать и перевести (на целевой язык)**: Транскрибирует речь и переводит её на ваш настроенный целевой язык.
3. **Озвучить и перевести (на целевой язык)** _(только Gemini)_: Мощная новая функция, которая транскрибирует речь, переводит её на ваш целевой язык и синтезирует озвученный дубляж с использованием TTS-движка дополнения.

## 8) Продвинутый читатель документов и изображений

**Чтение документов** превращает ваши документы в чистый, читаемый текст — так что вы можете читать, переводить и слушать всё: от отсканированной книги до стопки фотографий. Он обрабатывает многостраничные PDF, сложные изображения, форматы iPhone HEIC и даже простые текстовые (`.txt`) и HTML (`.html`, `.htm`) файлы, которые открываются мгновенно без OCR или обработки ИИ. Выберите несколько файлов сразу, и они объединяются в один непрерывный документ в порядке страниц. Доступны три OCR-движка — **Chrome (быстрый)**, **ИИ (расширенный)** для превосходного сохранения макета и **Нет (извлечь текстовый слой)** для PDF с возможностью поиска — выбираются в Настройки → Чтение документов.

### Как это работает

1. Нажмите **NVDA + Shift + V**, затем **D**, чтобы открыть чтение документов — или сначала выделите файл в Проводнике и нажмите **D** / **F**, чтобы пропустить диалог файла.
2. Выберите один или несколько PDF или изображений. Дополнение сканирует их и объявляет общее количество страниц.
3. В диалоге **Параметры** выберите диапазон страниц (С/По). Вы также можете отметить **Переводить результат** и выбрать целевой язык, или переключить **Описание изображений в процессе OCR**.
4. Извлечение текста начинается в фоне пакетами. Вы можете закрыть окно в любое время и продолжить позже — ничего не потеряется.
5. Когда страницы готовы, читайте их в просмотрщике: перемещайтесь между страницами, переходите к любой странице, задавайте вопросы ИИ, сохраняйте текст или генерируйте аудиоповествование.

### 7.1 Пакетная обработка и возобновление

Вам не нужно читать огромный документ сразу. Выберите диапазон страниц (например, `1-20`) или оставьте значения по умолчанию для обработки всего, и ИИ извлекает все страницы в фоне. Если NVDA упадёт или вы прервёте сканирование, дополнение запомнит ваш прогресс и предложит **возобновить** точно с того места, где остановилось — даже после перезапуска. Завершённые документы также кэшируются, поэтому повторное открытие (из недавних документов или через **D**) загружает текст мгновенно без повторного запуска OCR, если исходные файлы не изменились.

### 7.2 Умное действие с файлом

Вам не всегда нужно сначала открывать документ. В Проводнике Windows просто выделите PDF, изображение или текстовый/HTML-файл и нажмите **D** (Чтение документов) — или выделите PDF или изображение и нажмите **F** (Умное действие с файлом) — внутри командного слоя. Дополнение мгновенно обходит диалог файла и начинает обработку выделенного файла. Выбор нескольких файлов сразу обрабатывает их вместе как один документ.

### 7.3 Элементы управления и сочетания клавиш просмотрщика документов

Когда окно чтения документов открыто, вы можете использовать следующее:

#### Сочетания клавиш

- **Ctrl + PageDown / Ctrl + PageUp:** Перейти к следующей / предыдущей странице.
- **Down / Up Arrow:** Когда ваш курсор достигает последней строки страницы, нажмите **Down**, чтобы перейти к следующей странице; нажмите **Up** в начале страницы, чтобы вернуться к предыдущей.
- **Alt + A:** Открыть диалог чата для вопросов о документе.
- **Alt + R:** Принудительно выполнить **пересканировать с ИИ** с использованием вашего активного провайдера.
- **Alt + G:** Сгенерировать и сохранить высококачественный аудиофайл (WAV/MP3). _(Скрыто, если провайдер не поддерживает TTS)._
- **Alt + S / Ctrl + S:** Сохранить извлечённый текст как TXT или HTML-файл.

#### Кнопки и элементы управления

- **Перейти:** Выберите любую страницу из селектора страниц.
- **Просмотр с форматированием:** Просмотреть весь документ объединённым как форматированный текст.
- **Повторить неудачные страницы:** Повторить только те пакеты, которые не удались из-за временной ошибки сервера (например, высокая нагрузка). Эта кнопка появляется автоматически при необходимости.
- **Голос TTS / Движок TTS:** Выберите голос, и на Gemini выберите между **Стандартный TTS** и **Gemini Live** streaming.
- **Предыдущая / Следующая:** Перемещение между страницами (то же, что сочетания Ctrl+PageUp/Down).

### 7.4 Недавние документы (D)

Нажатие **D** в командном слое перечисляет ваши недавно прочитанные документы первыми. Выберите один, чтобы продолжить со страницы, на которой вы были — даже если OCR уже завершён — или нажмите **Открыть файл...** (`Ctrl + O`), чтобы выбрать файл как обычно.

## 9. Семантическая маркировка ИИ и обозреватель интерфейса

Застряли в приложении с «безымянными кнопками» повсюду? Движок семантической маркировки ИИ решает это навсегда.

### 8.1 Постоянная маркировка объектов (L)

Сфокусируйте ваш скринридер на безымянной графике или кнопке и нажмите **L** в командном слое. ИИ посмотрит на кнопку визуально, определит её функцию и применит постоянную метку.
_В отличие от старых инструментов маркировки скринридеров, это дополнение использует продвинутую гибридную систему «Object Signature» (AutomationId/ControlID). Ваши пользовательские метки выживут при изменении размера окна, переключении мониторов и обновлениях приложений!_

### 8.2 Полное сканирование приложения (Shift + L)

Нажмите **Shift + L**, чтобы сканировать всё активное окно сразу. ИИ найдёт все безымянные элементы и интеллектуально назовёт их за один раз. Позже вы можете управлять, переименовывать или пакетно удалять эти метки из встроенного менеджера меток.

### 8.3 Обозреватель интерфейса (E)

Нужно взаимодействовать с элементом, не переходя к нему вручную? Нажмите **E**, чтобы активировать обозреватель интерфейса. ИИ просканирует экран и сгенерирует доступный список каждого кликабельного элемента (игнорируя системный шум вроде панелей задач). Выберите элемент из списка, и дополнение мгновенно кликнет по нему за вас.

## 10. Живой голосовой помощник

The Live Assistant turns Vision Assistant Pro into a real-time, interactive copilot.
_(Note: This feature is exclusive to Google Gemini and Gemini-compatible Custom providers)._

- **Активация:** Нажмите **Control + L** в командном слое, чтобы открыть диалог Живого помощника.
- **Взаимодействие в реальном времени:** Говорите естественно через ваш микрофон. ИИ будет одновременно слушать ваш голос и смотреть на ваш активный экран. Вы можете задавать вопросы вроде «На что я смотрю?» или «Прочитай мне третий абзац».
- **Нажми и говори:** Включите **Нажми и говори** на вкладке настроек Живого помощника (или переключите прямо в окне Живого помощника), затем удерживайте назначенную клавишу, чтобы говорить, и отпустите, чтобы закончить. Это держит микрофон выключенным, пока вы не нажмёте клавишу — идеально для шумных сред.
- **Веб-камера:** Отметьте **Использовать &веб-камеру** в окне Живого помощника, чтобы отправлять вашу камеру ИИ вместо экрана — спрашивайте о физических объектах, печатных документах или вашем окружении. Если ffmpeg ещё не установлен, отметка этого флажка загрузит его один раз с вашего разрешения; опция отключена, когда камера не обнаружена или настройки конфиденциальности Windows блокируют доступ к камере.
- **Настройка:** Внутри диалога вы можете изменить голос TTS ИИ (например, Профессиональный, Дружелюбный, Энергичный) и настроить его **глубину мышления**, чтобы контролировать, насколько глубоко он рассуждает перед ответом.

## 11. Фоновый наблюдатель (фоновый помощник)

The Ambient Observer turns Vision Assistant Pro into your background eyes, without any conversation: it keeps listening and watching while you work, reports what changes, and stays silent when nothing happens.
_(Note: This feature is exclusive to Google Gemini and Gemini-compatible Custom providers)._

- **Исправления ошибок и улучшения стабильности**: Исправлено зависание во время генерации MP3 при закрытии диалога прогресса в середине задачи, устранено состояние гонки в хранилище словаря персонажей, добавлена надлежащая отчётность об ошибках кодирования MP3 и исправлен цикл ожидания в Чтении документов для учёта отмены пользователем.
- **Modes:** **Audio Translation Only** translates what it hears, **Screen Watcher Only** reports screen changes, and **Webcam Watcher Only** opens the Live Assistant window with your camera and Push to Talk, so you can ask questions about what the camera sees.
- **Audio Source:** In the audio mode, choose whether to translate your **Microphone** or the **System Audio (Loopback)**. The small loopback library is downloaded once on first use, with your permission.
- **Context:** For the screen and webcam modes, pick an optional **About what I am doing** option (for example watching a film, following a meeting or call, reading a label, or checking your appearance) to focus the reports; you can also type your own context.
- **Reporting:** The add-on compares every new frame with the previous one and sends it to the AI only when the picture really changed, so a static screen never costs you requests. The AI then reports only what is new and never repeats itself.
- **Welcome Message:** Except in the translation mode, the observer greets you briefly when it starts, so you know it is listening.
- **Settings:** In **Settings > Live Assistant**, set the **Observer Mode**, the **Frame Interval** (1 to 10 seconds) and the **Reporting Style** (brief or detailed). The observer instruction and each context text can be edited in the Prompt Manager (section **Ambient**).

## 12. Пользовательские запросы и переменные

Вы можете управлять запросами в **Настройки > Запросы > Управление запросами...**.

- **Filter:** The **Default Prompts** tab has a **Filter** list above the prompt list that shows **All** prompts or only one section at a time (for example **Ambient**), so long lists stay easy to navigate.

### Custom Prompt Shortcuts

Дайте любому пользовательскому запросу его собственную клавишу быстрого доступа прямо в менеджере запросов и запускайте его мгновенно с вашим текущим выделением или контекстом:

- **Одиночная клавиша** (например, `1`, `p` или `F3`): Работает внутри командного слоя, а также глобально как `NVDA + Shift + key`.
- **Комбинация клавиш** (например, `Control + Shift + 1`, `Alt + P` или `Insert + 1`): Работает глобально самостоятельно.

### Per-Prompt Feedback Behavior

Each custom prompt can individually define its output delivery behavior:

- **Global setting:** Follows the general Connection output setting (Direct Output or Chat window).
- **Copy to clipboard:** Copies the AI response directly to the clipboard without opening a window.
- **Провайдер ИИ MiniMax**: Интегрирован MiniMax как равноправный провайдер с полной мультимодальной поддержкой (чат, зрение, OCR), пользовательским TTS с использованием более 300+ динамических голосов и автоматическим удалением блоков рассуждений (например, ` thinking...`) из выводов.
- **Copy to clipboard and Direct Output:** Copies the response to the clipboard and speaks it directly.
- **Chat window:** Always opens the result in an interactive conversation window.

### Поддерживаемые переменные

- `[selection]`: Текущий выделенный текст.
- `[text]`: Complete text content of the currently focused edit field (automatically ignores protected password boxes).
- `[currentURL]`: Webpage or document URL from supported web browsers (Chrome, Edge, Firefox).
- `[clipboard]`: Содержимое буфера обмена.
- `[clipboard_image]`: Изображение, находящееся в буфере обмена.
- `[screen_obj]`: Снимок объекта навигатора.
- `[screen_fg_obj]`: Снимок активного окна переднего плана.
- `[screen_full]`: Снимок всего экрана.
- `[file_ocr]`: Выбрать изображение/PDF/TIFF для извлечения текста.
- `[file_read]`: Выбрать документ для чтения (TXT, код, PDF).
- `[file_audio]`: Выбрать аудиофайл для анализа (MP3, WAV, OGG).
- `[ambient_screen]`: Starts continuous Screen Observer background session.
- `[ambient_webcam]`: Starts continuous Webcam Observer background session (checks Push to Talk from settings).
- `[ambient_audio]`: Starts live Audio Observer translation session.
- `[loopback]`: Uses system audio playback as sound source (for `[ambient_audio]`).
- `[mic]`: Uses microphone as sound source (for `[ambient_audio]` and `[ambient_webcam]`).
- `[brief]`: Sets observer reporting style to brief (single sentence).
- `[detailed]`: Sets observer reporting style to detailed (2-3 sentences).
- `[lang:code]`: Specifies target language code for audio translation (e.g., `[lang:fa]`, `[lang:en]`).
- `{target_lang}`: Текущий целевой язык.
- `{source_lang}`: Текущий исходный язык.
- `{response_lang}`: Текущий язык ответов ИИ.
- `{swap_target}`: Резервный язык для перевода.
- `{swap_instruction}`: Инструкция для интеллектуального обменного перевода.

_Note on Ambient Prompts:_ Prompts containing ambient variables act as a toggle — pressing the shortcut while active immediately stops the session. Incompatible combinations (such as combining static screenshot variables like `[screen_full]` with ambient observer modes, combining multiple ambient modes, or adding prompt instructions to `[ambient_audio]`) are strictly validated and prevented when saving.

## 13. Реальные сценарии использования (Какую функцию мне использовать?)

Vision Assistant Pro упакован продвинутыми инструментами. Вот несколько распространённых сценариев, чтобы помочь вам выбрать правильный:

- **Сценарий: Вы хотите понять полную компоновку сложного окна или недоступного приложения.**
  _Решение:_ Нажмите **O** (Распознавание всего экрана). ИИ проанализирует весь экран и опишет, где именно расположены элементы, тексты и кнопки.

- **Сценарий: Вы нашли изображение на веб-странице или безымянную графику в документе.**
  _Решение:_ Переместите ваш объект навигатора на графику и нажмите **V** (Распознавание объекта). ИИ опишет именно то, что содержит это изображение.

- **Сценарий: Вы хотите посмотреть фильм или видеоклип с аудиоописаниями.**
  _Решение:_ Нажмите **Shift + V** на вашем видео и выберите **«Сгенерировать аудиоописание (SRT файл)»**. Когда он закончит, нажмите **«Сгенерировать синхронизированное озвучивание (MP3)»** и выберите **«Расширенное AD»**. Дополнение создаст аудиодорожку, которая интеллектуально приостанавливает диалог фильма для описания визуальных сцен.

- **Сценарий: Вы столкнулись с приложением, полным «безымянных кнопок».**
  _Решение:_ Нажмите **L**, чтобы навсегда пометить конкретную кнопку с помощью ИИ. Или нажмите **Shift + L**, чтобы сканировать и пометить всё окно сразу. Если вы просто хотите быстро что-то нажать, нажмите **E** (Обозреватель интерфейса), чтобы получить список всех кликабельных элементов.

- **Сценарий: Вам нужно обойти недоступную CAPTCHA.**
  _Решение:_ Нажмите **C** (Решение CAPTCHA). ИИ автоматически захватит CAPTCHA, решит её и вставит ответ в правильное поле.

- **Сценарий: Вы хотите прочитать длинный PDF-документ на 50 страниц.**
  _Решение:_ Нажмите **D** (Чтение документов), установите ваш провайдер на Google Gemini и введите диапазон страниц `1-50`. Дополнение точно извлечёт текст в фоне.

- **Сценарий: Вы смотрите беззвучное видео-руководство или анимацию на вашем экране.**
  _Решение:_ Нажмите **Control + V**, чтобы начать запись экрана. Дайте руководству воспроизвестись, затем нажмите **Control + V** снова. ИИ объяснит, что именно было продемонстрировано.

- **Сценарий: Вы столкнулись с неожиданной ошибкой, сбоем подключения к API или хотите диагностировать проблемы с пользовательскими локальными серверами.**
  _Решение:_ Перейдите в **Настройки > Дополнительно**, отметьте **«Включить отдельный файл журнала»** и установите **уровень журналирования** на **«Отладка (все детали)»**. Выполните действие снова, затем нажмите **«Открыть файл журнала»**, чтобы просмотреть технические детали или прикрепить `vision_assistant.log` к тикету поддержки.

**Примечание:** Для всех функций ИИ требуется активное интернет-соединение. Многостраничные документы обрабатываются автоматически.

\*   \*\*Анализ онлайн-видео:\*\* Добавлена новая функция для анализа видео YouTube и Instagram напрямую путём предоставления URL.

- **Интеграция с буфером обмена:** Добавлена новая настройка для автоматического копирования ответов ИИ в буфер обмена.

- **Оптимизация запросов:** Улучшена логика перевода и структурированы результаты Распознавания.

## Изменения для 2.0

- **Добавлены французский и турецкий переводы.**
- **Форматированный просмотр:** Добавлена кнопка «Просмотр с форматированием» в диалогах чата для просмотра разговора с правильным стилем (заголовки, жирный шрифт, код) в стандартном окне с возможностью просмотра.
