# Документація Vision Assistant Pro

<!-- DOWNLOAD_COUNT_START --> Загальна кількість завантажень: 62 863 <!-- DOWNLOAD_COUNT_END -->

**Vision Assistant Pro** — це вдосконалений мультимодальний ШІ-помічник для NVDA. Він використовує механізми штучного інтелекту світового класу, щоб забезпечити інтелектуальне читання з екрана, переклад, голосовий диктант і аналіз документів.

_Цей додаток був випущений для спільноти на честь Міжнародного дня людей з інвалідністю._

## ## 1. Встановлення та налаштування

Перейдіть до **Меню NVDA > Параметри > Налаштування > Vision Assistant Pro**. Діалог налаштувань поділено на 9 доступних вкладок: **З'єднання**, **Live помічник**, **Поведінка ШІ**, **Мови перекладу**, **Читач документів**, **Відео**, **КАПЧА**, **Підказки** та **Розширене**.

### 1.1 Вкладка «Параметри підключення»

- **Постачальник:** Виберіть бажаний сервіс штучного інтелекту. Підтримувані постачальники: **Google Gemini**, **OpenAI**, **Mistral**, **Groq**, **MiniMax**, **Користувацькі** (OpenAI-сумісні сервери, такі як Ollama/LM Studio), Jan.ai, або KoboldCPP.
- **Важлива примітка:** Ми наполегливо рекомендуємо використовувати **Google Gemini** для найкращої продуктивності та точності (особливо для аналізу зображень/файлів).
- **Отримати моделі:** Після введення ключа API натисніть цю кнопку, щоб завантажити останній список доступних моделей від постачальника.
- **Модель ШІ:** Виберіть основну модель, яка використовується для загального чату та аналізу.
- **Розширена модель маршрутизації (для конкретних завдань):** За потреби виберіть спеціальні моделі з випадаючих списків для завдань OCR, STT, TTS, оператора ШІ, відео та Live помічника. Для Gemini моделі динамічно розподіляються за можливостями: **Швидкі/Економічні**, **Стандартні**, **Найрозумніші (Pro)** або **Тільки звук** (для голосового Live помічника).
- **Налаштування користувацького постачальника:** Налаштуйте локальні або користувацькі кінцеві точки. Включає **Налаштування локального ШІ** (налаштування одним натисканням для Ollama, LM Studio, Jan.ai або KoboldCPP) та **Розширене налаштування кінцевої точки**.
- **Налаштування проксі:** Повна підтримка тунелювання та перенаправлення кінцевих точок у всьому додатку (включно з Live помічника, спостерігача та TTS). Введіть **URL проксі** та виберіть **режим проксі**:
  - **Автоматичне визначення:** Автоматично визначає, чи є URL прямим чи зворотним проксі-сервером.
  - **Проксі SOCKS5:** Примусово вмикає пряме тунелювання через SOCKS5 з автентифікацією за допомогою імені користувача та пароля відповідно до RFC 1929 та розпізнаванням доменних імен.
  - **HTTP-проксі:** Примусово здійснює пряме тунелювання через HTTP-проксі з базовою автентифікацією.
  - **Зворотний проксі:** Пряма заміна кінцевої точки для власних шлюзів ШІ та самостійно розміщених дзеркал (у цьому режимі облікові дані вимкнені).
- **Автоматичне визначення:** Автоматично визначає, чи є URL прямим чи зворотним проксі-сервером.
- **Проксі SOCKS5:** Примусово вмикає пряме тунелювання через SOCKS5 з автентифікацією за допомогою імені користувача та пароля відповідно до RFC 1929 та розпізнаванням доменних імен.
- **HTTP-проксі:** Примусово здійснює пряме тунелювання через HTTP-проксі з базовою автентифікацією.

### 1.2 Вкладка «Live помічник»

- **Live помічник: Прямий вивід (без вікна):** Запустіть Live помічника без діалогу; відкрийте його пізніше за допомогою клавіші «Показати останній результат» (`Пробіл`).
- **Натисніть, щоб говорити**: Увімкнути/вимкнути режим «натисніть, щоб говорити». Якщо його ввімкнено, мікрофон надсилатиме звук лише тоді, коли ви утримуєте призначену клавішу.
- **Клавіша «Натисніть, щоб говорити»:** натисніть клавіші, щоб призначити комбінацію (наприклад, `F12` або `Ctrl+F12`) — ви навіть можете призначити окрему клавішу-модифікатор, таку як `Лівий Ctrl`. Утримуйте клавішу, щоб говорити, і відпустіть її, щоб завершити; короткий звуковий сигнал підтверджує кожне натискання та відпускання.

Примітка: Ця вкладка показується лише тоді, коли активним постачальником послуг є **Google Gemini** (або сумісний із Gemini користувацький постачальник).

### 1.3 Вкладка «Поведінка ШІ»

- **Креативність (Температура):** Регулює ступінь випадковості та креативності ШІ (від 0,0 до 2,0). Нижчі значення забезпечують більш детерміновані та точні результати перекладу/OCR.

### 1.4 Вкладка «Мови перекладу»

- **Початкова мова:** Виберіть мову введення.
- **Мова для перекладу:** Виберіть мову перекладу.
- **Мова відповідей ШІ:** Виберіть мову для загальних відповідей ШІ.
- **«Автоматична зміна мови»:** Автоматично змінює місцями мови оригіналу та перекладу на основі виявленого введеного тексту.

### 1.5 Вкладка «Читач документів»

- **Механізм OCR:** Виберіть між **Chrome (Швидкий)** для швидких результатів або **ШІ (Розширений)** для кращого збереження форматування.
- **Розмір пакета OCR:** Вкажіть кількість сторінок на запит (встановіть значення 0 для обробки одного запиту).
- **Опис зображень у тексті:** увімкніть або вимкніть опис зображень у тексті під час видобування тексту з документа.
- **Експорт номерів сторінок:** увімкніть або вимкніть показ номерів сторінок та роздільників у багатосторінкових документах.
- **Голос TTS:** виберіть початковий стиль голосу для генерації аудіо.
- **Збереження документів в історії:** Зберігайте відкриті документи в списку історії; кешований текст OCR і дані для продовження також зберігаються.

### 1.6 Вкладка «Відео»

- **Розмір фрагмента відео:** Тривалість сегмента в хвилинах для генерації аудіоопису (встановіть значення 0, щоб обробити весь файл).
- **Додати список персонажів:** Функція додавання словника персонажів як першого запису субтитрів.
- **Додати застереження щодо ШІ:** Функція вставки застереження щодо ШІ на початку субтитрів SRT до відео.
- **Словник персонажів та керування серіалами:** додавайте, редагуйте, імпортуйте або керуйте іменами персонажів, їхніми фізичними характеристиками та ролями для кожного серіалу — ШІ автоматично зіставляє виявлених персонажів із вашим словником і додає нових у міру того, як ви аналізуєте нові епізоди. Ваші ручні нотатки завжди зберігаються і мають пріоритет над оновленнями від ШІ, тоді як фізичні характеристики персонажів залишаються актуальними у всіх епізодах.

### 1.7 Вкладка «КАПЧА»

- **Увімкнути розпізнавання візуальних CAPTCHA:** Увімкнути або вимкнути розпізнавання візуальних CAPTCHA (hCaptcha, reCAPTCHA).
- **Метод розпізнавання текстових CAPTCHA:** Оберіть між захопленням **об’єкта навігатора** або **всього екрана**.

### 1.8 Вкладка «Підказки»

- **Керування підказками:** відкриває спеціальний діалог для налаштування системних підказок або створення, редагування, зміни порядку та попереднього перегляду власних підказок із динамічними змінними (наприклад, `[selection]`, `[screen_fg_obj]`, `[currentURL]`, `[text]`).
- **Налаштовувані комбінації клавіш для підказок:** Призначте окрему комбінацію клавіш для будь-якої налаштовуваної підказки безпосередньо в «Менеджері підказок». Натисніть клавіші, щоб їх записати — окремі клавіші спрацьовують у командному шарі (а також глобально як `NVDA + Shift + клавіша`), тоді як комбінації на кшталт `Control + Shift + 1` спрацьовують глобально самостійно.
- **Поведінка зворотного зв’язку для кожного запиту:** Виберіть, як для кожного запиту окремо показуватиметься результат (загальне налаштування, копіювання в буфер обміну, прямий вивід / повідомлення NVDA, копіювання в буфер обміну + прямий вивід або діалог чату).

### 1.9 Вкладка «Додаткові налаштування» та глобальне ведення журналу

Перейдіть на вкладку **«Розширене»**, щоб налаштувати глобальне ведення журналу для додатка:

- **Увімкнути окремий файл журналу:** вмикає або вимикає запис усіх операційних подій, трафіку API та помилок у всіх модулях додатка в окремий файл (`vision_assistant.log`).
- **Рівень журналу:** виберіть рівень деталізації: **Debug (усі деталі)**, **Info (загальна інформація)**, **Warning (лише попередження)** та **Error (лише помилки)**.
- **Зберігати журнали протягом:** Встановіть автоматичні періоди зберігання, щоб автоматично очищати старі записи журналу (від 1 години до 90 днів).
- **Елементи керування журналами:** Використовуйте **Відкрити файл журналу**, **Відкрити папку журналу** або **Очистити файл журналу**, щоб переглянути або очистити дані журналу безпосередньо, не перезапускаючи NVDA та не впливаючи на стандартні журнали NVDA.
- **Уніфікований каталог даних:** Усі файли даних додатка (історія, серіали, підписи, перебіг виконання OCR, кеші та журнали) зберігаються в єдиній папці `VisionAssistant` у каталозі налаштувань NVDA — це дозволяє підтримувати порядок і спрощує створення резервних копій вручну.

### 1.10 Резервне копіювання та відновлення налаштувань

Вкладка **«Розширене»** також містить розділ **«Резервне копіювання та відновлення»**:

- **Резервне копіювання:** Зберігає вашу конфігурацію в одному файлі JSON. Натиснувши цю функцію, ви обираєте, що включити: **Все** (налаштування, власні підписи, перебіг виконання OCR та історію) або **Тільки налаштування**.
- **Відновлення:** завантажує раніше збережену резервну копію для відновлення ваших налаштувань та даних у будь-який час, на будь-якому комп’ютері або після перевстановлення NVDA. Спочатку вам буде запропоновано підтвердити дію, оскільки відновлення замінить усі ваші поточні налаштування та дані.

## 2. ## 2. Менеджер ключів API Gemini

Створення ключа API Gemini на сайті **aistudio.google.com** раніше було найскладнішим етапом роботи з цим додатком. При використанні екранного зчитувача сторінки були заплутаними, і деякі користувачі просто не могли створити ключ. **Менеджер ключів API Gemini** вирішує цю проблему. Натисніть **G** у командному шарі або відкрийте **Меню NVDA > Параметри > Налаштування > Vision Assistant > З’єднання** і натисніть **Отримати ключ API Gemini...**.

- **Вхід:** Коли ви відкриваєте менеджер, ваш початковий браузер одразу відкриває захищену сторінку входу в Google. Увійдіть за допомогою свого облікового запису Google — зовнішні інструменти, SDK чи налаштування командного рядка не потрібні. Обліковий запис, під яким ви увійшли, завжди показується на кнопці **Вийти**.
- **Створення ключа:** Після входу ви можете одразу створити ключ за допомогою функції **Новий проєкт та ключ** без будь-яких попередніх налаштувань. Якщо у вас уже є існуючі проєкти, вони з’являться у простому списку, де ви можете вибрати один із них і натиснути **«Створити ключ для вибраного проєкту»**.
- **Що відбувається далі:** Новий ключ одразу копіюється в буфер обміну, зберігається в додатку для подальшого використання, і вам один раз буде запропоновано додати його до списку ключів додатка. Це все, що вам потрібно — не потрібно шукати інформацію на веб-сторінках.
- **Робота з ключами:** **«Скопіювати ключ для вибраного проєкту»** копіює ключ вибраного вами проєкту, **«Скопіювати останній створений ключ»** — ключ, який ви створили щойно, а **«Експортувати збережені ключі у CSV...»** — зберігає у файл усі створені вами ключі.
- **Видалення ключа:** **Видалити ключ...** показує ключі, що існують у вибраному проєкті, запитує, який саме видалити, і підтверджує перед видаленням. Видалення ключа також видаляє його зі списку ключів додатка, тож для зміни ніколи не залишається пошкоджених ключів. Ключі, створені поза додатком, також можна видалити, якщо ваш обліковий запис має дозвіл на цей проєкт.
- **Вихід із системи:** **Вийти** видаляє збережену інформацію для входу з вашого комп’ютера, тож ви можете перейти на інший обліковий запис у будь-який час.

## ## 3. Командний шар і комбінації клавіш

Щоб запобігти конфліктам клавіатури, цей додаток використовує **командний шар**.

1. Натисніть **NVDA + Shift + V** (головна клавіша), щоб активувати командний рівень (ви почуєте звуковий сигнал).
2. Відпустіть клавіші, а потім натисніть одну з наступних клавіш:

Повторне натискання миттєво перериває активні операції.                                                                                                                           |
| **E**                          | **UI Провідник**                  | **Інтерактивне натискання:** Виявляє та натискає елементи інтерфейсу в будь-якій програмі.                                                                                                                                                                                   |
| **T**                          | Розумний перекладач               | Перекладає текст під курсором навігатора або виділений текст.                                                                                                                                                                                                                                |

## ## 4. Чат та історія

Діалог чату та діалог історії працюють у всіх функціях, тож ви можете переглядати розмови та продовжувати спілкування з того місця, де ви зупинилися.

### 4.1 Комбінації клавіш у діалозі чату

Коли відкрито діалог чату (прямий чат, чат у документі, діалог уточнення тощо), ви можете переглядати перебіг розмови за допомогою таких комбінацій клавіш:

- **Alt + «стрілка Вниз»:** перейти до наступного повідомлення.
- **Alt + «стрілка Вгору»:** перейти до попереднього повідомлення.
- **Alt + C:** скопіювати поточне повідомлення.

### 4.2 Історія (Control + H)

Натисніть **Control + H** у командному шарі, щоб відкрити діалог **Історія** з вашими минулими чатами та документами, які можна фільтрувати за типом (Усі / Чати / Документи). Відкрийте чат, щоб продовжити розмову — включаючи вкладені файли, які автоматично додаються знову, — або відкрийте документ і продовжуйте читати. Натисніть **Delete** на будь-якому елементі, щоб видалити його, або **Очистити все**, щоб очистити список. Для документів клавіша Delete запитує, чи хочете ви видалити лише запис історії, чи також стерти збережений у кеші розпізнаний текст.

Ви також можете вибрати, що саме додаток має запам’ятовувати. Функції **«Зберегти чати в історії»** (вкладка «З’єднання») та **«Зберегти документи в історії»** (вкладка «Читач документів») початково увімкнені, і обидві їх можна ввімкнути або вимкнути в «Швидких налаштуваннях». Параметр щодо документів впливає лише на записи в історії — кешований текст, отриманий за допомогою OCR, та дані відновлення завжди зберігаються.

## ## 5. Оператор ШІ – автономне комп’ютерне керування

**Оператор ШІ** перетворює Vision Assistant Pro з пасивного зчитувача на активного помічника, який може взаємодіяти з комп'ютером замість вас. Ви можете просити його описати екран, відповісти на запитання про те, що він бачить або навіть надати йому керування: він натискатиме кнопки, перетягуватиме об’єкти, вводитиме текст і працюватиме в програмах за допомогою звичайних голосових чи текстових команд.

Найбільша перевага? Додаток бездоганно працює навіть у програмному забезпеченні, яке взагалі не підтримує функції доступності. Якщо ви опинилися в ситуації, коли екранний зчитувач повністю замовкає — наприклад, у програмі, на віддаленому робочому столі або на веб-сайті, — оператору це не заважає. Оскільки додаток «бачить» екран візуально, він може знаходити, зчитувати та взаємодіяти з елементами, які не мають жодних міток доступності.

### 5.1 Як це працює

1. Натисніть **NVDA + Shift + V**, потім **Shift + A** (або використайте пряму комбінацію клавіш), щоб відкрити діалог оператора ШІ.
2. 2. Введіть своє завдання звичайною мовою (наприклад, «Натисни кнопку Зберегти», «Що написано в повідомленні про помилку?» або «Перейменуй файл у final.pdf»).
3. ШІ проаналізує ваш екран, визначить відповідні елементи та виконає дію або надасть відповідь. ШІ проаналізує ваш екран, знайде потрібні елементи, виконає дію або надасть відповідь. Якщо завдання складне, оператор виконуватиме його поетапно до завершення.
4. Натисніть **Shift + A** у будь-який момент, щоб миттєво перервати поточну операцію.

### 5.2 Підтримувані дії

Оператор розуміє широкий спектр команд:

- **Опис та відповідь**: «Опиши розташування елементів на екрані» або «Що написано в повідомленні про помилку?»
- **Натиснути**: «Натисни кнопку “Зберегти”»
- **Клацнути правою кнопкою**: «Клацає правою кнопкою миші на файлі»
- **Двічі клацнути**: «Двічі клацає на документі»
- **Перетягнути**: «Перетягни документ у папку “Архів”»
- **Ввести**: «Введи «Погода сьогодні» у поле пошуку»
- **Прокрутити**: «Прокрути вниз три рази»
- **Натиснути клавішу**: «Натисни Enter», «Натисни Tab», «Натисни Escape»
- **Багатоетапні завдання**: «Відкрий Провідник, знайди звіт і перейменуй його на final.pdf»

### 5.3 Важливі примітки

- **⚠️ Попередження щодо використання API**: Оскільки оператору потрібно «бачити» саме те, що відбувається на екрані, він надсилає знімок екрана з високою роздільною здатністю на кожному кроці. Часте використання цієї функції вичерпає вашу квоту API набагато швидше, ніж стандартні текстові функції.
- **Застосування з правами адміністратора**: Якщо NVDA не працює з правами адміністратора, користувач може не мати можливості взаємодіяти з вікнами, що вимагають підвищених прав доступу. Це обмеження системи безпеки Windows, а не помилка у роботі додатка.
- **Рекомендації**: Для досягнення найкращих результатів давайте чіткі та конкретні вказівки. Фраза «Натисни синю кнопку «Відправити» внизу форми» майже завжди дасть кращий результат, ніж просто «Натисни кнопку».

### 5.4 Live оператор (Control+A)

Функція «Live оператор» дозволяє «Live помічнику» виконувати ваші запити на комп’ютері під час розмови з ним, у тому числі в програмах, які не може прочитати ваш екранний зчитувач.
_(Примітка: ця функція доступна лише для Google Gemini та користувацьких провайдерів, сумісних із Gemini)._

- **Активація:** Натисніть **Control+A** у командному шарі, щоб розпочати сеанс роботи live оператора; натисніть цю комбінацію ще раз, щоб завершити сеанс.
- **Як це працює:** Задавайте запити простою мовою, наприклад: «Відкрий Chrome і знайди веб-сайт» або «Перейменуй цей файл на final». Оператор дивиться на екран, виконує кроки один за одним і продовжує працювати над багатоетапними запитами, доки завдання не буде виконано.
- **Повідомлення:** Кожен крок озвучується власним голосом Live помічника, і він повідомляє вас, коли завдання виконано, або чому його не вдалося виконати.
- **CAPTCHA:** Якщо з’являється CAPTCHA, оператор спочатку спробує використати ваш вбудований **розв’язувач CAPTCHA**; якщо він не зможе її розв’язати, він попросить вас самостійно виконати доступне завдання.
- **Зупинення:** Натисніть **«Припинити дію оператора»** у діалозі Live помічника, щоб скасувати поточне завдання.
- **Налаштування:** Власну інструкцію оператора можна редагувати в «Менеджері підказок» (розділ **Live**, **Інструкція Live оператора**). Перемикач **«Прямий вивід Live (без вікна)»** також доступний у «Швидких налаштуваннях».

## ## 6. Аналіз відео та аудіоопис

> > **Примітка:** Функції аналізу відео та аудіоопису надаються виключно постачальником **Google Gemini**. Переконайтеся, що в налаштуваннях додатка вибрано Google Gemini як активного постачальника.

Vision Assistant Pro пропонує потужні можливості обробки відео, розроблені спеціально для незрячих користувачів. Він може аналізувати як онлайн-відео, так і локальні записи з екрана, щоб надавати високодетальні візуальні описи та створювати професійні сценарії аудіоопису (SRT).

### 6.1 Локальний запис екрана (Control + V)

Якщо на екрані з’явилося відео без звуку, анімація або навчальний посібник, ви можете записати його безпосередньо:

1. Натисніть **NVDA + Shift + V**, щоб перейти до командного шару, а потім натисніть **Control + V**.
2. Додаток почне непомітно записувати екран у фоновому режимі.
3. Натисніть **Control + V** ще раз, щоб зупинити запис.
4. Після цього ШІ проаналізує записаний фрагмент відео та надасть дуже детальний опис сцени, персонажів та дій.

### 6.2 Аналіз відео (Shift + V)

Ви можете аналізувати як локальні відеофайли, так і онлайн-відео. Просто виберіть локальний відеофайл у Провіднику Windows або скопіюйте посилання на онлайн-відео в буфер обміну. Ви також можете натиснути **Shift + V** у будь-якому місці (наприклад, у медіаплеєрі), щоб відкрити діалог, де можна вибрати відеофайл або вручну ввести URL.

- **Підтримувані онлайн-платформи:** YouTube, Instagram, TikTok та Twitter (X).
- ШІ автоматично виявить локальний файл або URL, обробить відео та надасть вичерпний візуальний опис та аудіоопис.
- **48-годинне кешування відеофайлів:** Відео, завантажені на Gemini, зберігаються в кеші протягом 48 годин! Ви можете повторно генерувати SRT- або MP3-файли для того самого відео без повторного завантаження — навіть після перезапуску NVDA. Кеш враховує ключ і автоматично анулюється у разі зміни вашого API-ключа.

### 6.3 Генерація аудіоопису (SRT)

Для більш структурованої взаємодії додаток може генерувати професійні сценарії аудіоопису у стандартному форматі SubRip (SRT).

- **Розумний таймінг пауз:** ШІ аналізує аудіодоріжку та прив’язує візуальні описи безпосередньо до природних пауз та інтервалів тиші, що дозволяє інтелектуально мінімізувати перекриття діалогів.
- **Відстеження персонажів:** Сервіс здійснює попередній аналіз для виявлення унікальних персонажів на основі незмінних рис обличчя. Він створює глобальний словник для точного відстеження та підпису персонажів у різних сценах без виникнення плутанини. Він також відстежує **першу появу** кожного персонажа, описуючи його зовнішність та одяг для зручності контексту.
- **Дослівне розпізнавання тексту:** Будь-який текст, що з’являється на екрані (вивіски, екрани телефонів, титри), цитується строго дослівно.
- **Інструкція з використання:** Щоб прослухати згенеровані субтитри, просто помістіть файл `.srt` в ту саму папку, що й відеофайл, і дайте йому точно таку саму назву. Потім налаштуйте свій медіаплеєр (наприклад, VLC або PotPlayer) для перенаправлення тексту субтитрів безпосередньо на ваш екранний зчитувач або рушій синтезу мовлення (TTS) під час відтворення.
- **Покращено збереження:** Під час збереження файлів SRT або MP3 діалог файлу тепер початково відкривається в папці вихідного відео, незалежно від того, чи відкрили ви відео через діалог файлу чи за допомогою Shift+V у Провіднику.

### 6.4 Синхронізований аудіоопис (експорт в MP3)

Окрім простого створення текстових файлів SRT, додаток функціонує як повноцінний інструмент для створення аудіоопису, синтезуючи описи у мовлення та мікшуючи їх із відео. Тепер ви можете обрати **Gemini Live TTS** як голосовий рушій, який використовує Gemini Live API для створення дуже реалістичного голосового озвучення без обмежень. Під час створення MP3-файлу для локальних відеофайлів у вас є кілька режимів мікшування:

- **Стандартний аудіоопис (мікшування голосу):** Аудіоопис накладається безпосередньо поверх оригінального звуку відео. Вам буде запропоновано застосувати **приглушення звуку** (зниження фонової гучності під час відтворення опису) для забезпечення чіткості мовлення.
- **Розширений аудіоопис (пауза аудіо):** Додаток призупиняє оригінальний звук відео під час відтворення описів, гарантуючи, що ви не пропустите жодного слова з оригінального діалогу або озвучення від ШІ. Для виявлення тиші тепер використовується нейромережева модель **Silero VAD** (завантажується автоматично при першому використанні), яка значно точніше визначає паузи у мовленні порівняно зі звичайними пороговими значеннями гучності.
- **Відео з YouTube:** Для джерел із YouTube (які не завантажуються локально) експортований MP3-файл міститиме виключно синхронізовану голосову доріжку ШІ без фонового звуку відео.

## ## 7. Транскрипція та дубляж медіа (M) Транскрипція та дубляж медіа (M)

Аудіотранскриптор було повністю перероблено для підтримки як аудіо, так і відеофайлів (MP3, WAV, MP4, MKV тощо). Натисніть **M** у командному шарі, щоб вибрати медіафайл і вибрати один із 3 різних режимів роботи:

1. **Транскрибувати (мова оригіналу)**: точно транскрибує мовлення мовою оригіналу.
2. **Транскрипція та переклад (мова для перекладу)**: транскрибує мовлення та перекладає його на вибрану вами мову для перекладу.
3. **Дублювання та переклад (мова для перекладу)** _(лише для Gemini)_: потужна нова функція, яка транскрибує мовлення, перекладає його на вибрану вами мову для перекладу та озвучує аудіодубляж за допомогою TTS додатка.

## ## 8. Просунутий читач документів та зображень

**Читач документів** перетворює ваші документи на чіткий, читабельний текст — тож ви можете читати, перекладати та прослуховувати будь-що: від відсканованої книги до купи фотографій. Додаток підтримує багатосторінкові PDF-файли, складні зображення, формат HEIC для iPhone, а також файли у форматі простого тексту (`.txt`) та HTML (`.html`, `.htm`), які відкриваються миттєво без OCR-обробки чи використання ШІ. Виберіть кілька файлів одночасно, і вони будуть об’єднані в один суцільний документ у порядку сторінок. Доступні три механізми OCR — **Chrome (Швидкий)**, **ШІ (Розширений)** для найкращого збереження форматування та **Немає (Видобути текстовий шар)** для PDF-файлів із можливістю пошуку — їх можна вибрати в меню «Налаштування» → «Читач документів».

### Як це працює

1. Натисніть **NVDA + Shift + V**, а потім **D**, щоб відкрити «Читач документів» — або спочатку виберіть файл у Провіднику файлів і натисніть **D** / **F**, щоб повністю пропустити діалог вибору файлу.
2. 2. Виберіть один або кілька PDF-файлів чи зображень. Додаток просканує їх і оголосить загальну кількість сторінок.
3. У діалозі **Параметри** виберіть діапазон сторінок (Від/До). У діалозі **Параметри** виберіть діапазон сторінок (Від/До). Ви також можете встановити прапорець **Перекласти результат** і вибрати мову перекладу, або увімкнути/вимкнути функцію **Описувати зображення під час OCR**.
4. Видобування тексту починається у фоновому режимі пакетами. Видобування тексту починається у фоновому режимі пакетами. Ви можете закрити діалог в будь-який момент і продовжити пізніше — нічого не загубиться.
5. Коли сторінки будуть готові, перегляньте їх у переглядачі: переходьте між сторінками, переходьте до будь-якої сторінки, задавайте питання ШІ, зберігайте текст або створюйте аудіоопис.

### 8.1 Пакетна обробка та поновлення

Вам не потрібно читати великий документ за один раз. Введіть діапазон сторінок (наприклад, `1-20`), і ШІ обробить усі сторінки у фоновому режимі. Якщо NVDA зависне або ви перервете сканування, додаток запам’ятає ваш перебіг виконання і запропонує **відновити** саме з того місця, де ви зупинилися. Оброблений документ зберігається у кеші, тому його повторне відкриття (з Нещодавніх документів чи через Історію) відбувається миттєво.

### 8.2 Розумна дія з файлом

Не завжди потрібно спочатку відкривати документ. У Провіднику Windows просто виберіть PDF-файл або зображення та натисніть **D** (Читач документів) або **F** (Розумна дія з файлом) у командному шарі. Додаток миттєво пропустить діалог файлу та почне обробку вибраного файлу. Вибір кількох файлів одночасно обробляє їх разом як один документ, дозволяючи читати їх послідовно.

### 8.3 Комбінації клавіш для перегляду документів

Коли діалог «читача документів» відкритий, ви можете використовувати такі комбінації клавіш:

#### Комбінації клавіш

- **Ctrl + PageDown / Ctrl + PageUp:** Перехід до наступної / попередньої сторінки.
- **Стрілка вниз / вгору:** Коли курсор досягне останнього рядка сторінки, натисніть **вниз**, щоб перейти на наступну сторінку; натисніть **вгору** у верхній частині сторінки, щоб повернутися до попередньої.
- **Alt + A:** відкрити діалог чату, щоб задати питання щодо документа.
- **Alt + R:** Примусово запустити **повторне сканування за допомогою ШІ** з використанням активного постачальника.
- **Alt + G:** Створити та зберегти високоякісний аудіофайл (WAV/MP3). _(Приховано, якщо постачальник не підтримує TTS)._
- **Alt + S / Ctrl + S:** Зберегти видобутий текст як файл у форматі TXT або HTML.

#### Кнопки та елементи керування

- **Перейти до:** Виберіть будь-яку сторінку з меню вибору сторінок.
- **Переглянути у форматованому вигляді:** Перегляньте весь документ у вигляді форматованого тексту.
- **Повторити спробу для сторінок, що не завантажилися:** Повторіть спробу лише для тих пакетів, завантаження яких не вдалося через тимчасову помилку сервера (наприклад, через велике навантаження). Ця кнопка з’являється автоматично за потреби.
- **Голос TTS / Механізм TTS:** Оберіть голос, а в Gemini — виберіть між **Стандартним TTS** та потоковим **Gemini Live**.
- **Попередня / Наступна:** Перехід між сторінками (аналогічно комбінаціям клавіш Ctrl+PageUp/Down).

### 8.4 Нещодавні документи (D)

Натискання клавіші **D** у командному шарі показує список документів, які ви нещодавно переглядали. Виберіть один із них, щоб продовжити з тієї сторінки, на якій ви зупинилися — навіть якщо OCR вже завершився — або натисніть **Відкрити файл...** (`Ctrl + O`), щоб вибрати файл у звичайному режимі.

## ## 9. Семантичний підпис за допомогою ШІ та дослідник інтерфейсу користувача

Застрягли в програмі, де всюди «кнопки без підписів»? Механізм семантичного підпису на основі ШІ вирішує цю проблему раз і назавжди.

### 9.1 Постійне підписування об’єктів (L)

Сфокусуйте графічний елемент або кнопку без підпису та натисніть **L** у командному шарі. ШІ візуально проаналізує кнопку, визначить її функцію та застосує постійний підпис.
_На відміну від старих інструментів підпису для екранних зчитувачів, цей додаток використовує вдосконалену гібридну систему «Object Signature» (AutomationId/ControlID). Ваші власні підписи збережуться навіть після зміни розміру вікна, перемикання моніторів та оновлень програми!_

### 9.2 Повне сканування програми (Shift + L)

Натисніть **Shift + L**, щоб одночасно просканувати все активне вікно. ШІ знайде всі елементи без підписів і розумно присвоїть їм назви за один раз. Пізніше ви зможете керувати цими підписами, перейменовувати їх або видаляти пакетно за допомогою вбудованого менеджера підписів.

### 9.3 Провідник інтерфейсу користувача (E)

Потрібно взаємодіяти з елементом, не переходячи до нього вручну? Натисніть **E**, щоб активувати Провідник інтерфейсу користувача. ШІ просканує екран і згенерує доступний список усіх клікабельних елементів (ігноруючи системний шум, такий як панелі завдань). Виберіть елемент зі списку, і додаток миттєво клацне по ньому.

## ## 10. Голосовий Live помічник

Live Помічник перетворює Vision Assistant Pro на інтерактивного помічника, що працює в режимі реального часу.
_(Примітка: ця функція є ексклюзивною для Google Gemini та сумісних із Gemini провайдерів; вимагає окремого ключа API Gemini)._

- **Активація:** Натисніть **Control + L** у командному шарі, щоб відкрити діалог Live помічника.
- **Взаємодія в режимі реального часу:** Говоріть природно через мікрофон. ШІ одночасно слухатиме ваш голос і стежитиме за активним екраном. Ви можете задавати питання на кшталт «На що я дивлюся?» або «Прочитай мені третій абзац».
- **Натисніть, щоб говорити:** Увімкніть функцію **Натисніть, щоб говорити** на вкладці налаштувань Live помічника (або увімкніть її безпосередньо у діалозі Live помічника), а потім утримуйте призначену клавішу, щоб говорити, і відпустіть її, щоб закінчити. У такому разі мікрофон залишатиметься вимкненим, доки ви не натиснете клавішу — це ідеально підходить для шумних місць.
- **Використання з веб-камери:** Поставте прапорець біля пункту **Використовувати веб-камеру** у діалозі Live Assistant, щоб надсилати ШІ зображення з камери замість екрана — запитуйте про фізичні об’єкти, роздруковані документи або оточення. Якщо ffmpeg ще не встановлено, при позначенні відповідного прапорця програма завантажиться один раз з вашого дозволу; ця опція вимкнена, якщо камера не виявлена або налаштування конфіденційності Windows блокують доступ до камери.
- **Налаштування:** У діалозі ви можете змінити стиль голосу ШІ (наприклад, «Професійний», «Дружній», «Жвавий») та налаштувати його «Глибину міркування», щоб контролювати, наскільки глибоко він міркує перед тим, як відповісти.

## ## 11. Спостерігач (фоновий помічник)

Спостерігач перетворює Vision Assistant Pro на ваші очі, без жодної розмови: він постійно слухає та спостерігає за вашою роботою, повідомляє про зміни та мовчить, коли нічого не відбувається.
_(Примітка: ця функція є ексклюзивною для Google Gemini та сумісних із Gemini провайдерів; вимагає окремого ключа API Gemini)._

- **Активація:** Натисніть **Shift+O** у командному шарі, щоб відкрити діалог спостерігача; натисніть цю комбінацію ще раз, щоб зупинити роботу спостерігача.
- **Режими:** **«Тільки переклад аудіо»** перекладає те, що чує; **«Тільки спостереження за екраном»** повідомляє про зміни на екрані; а **«Тільки спостереження за веб-камерою»** відкриває діалог Live помічника із вашою камерою та функцією «Натисніть, щоб говорити», щоб ви могли задавати питання про те, що бачить камера.
- **Джерело аудіо:** У аудіорежимі виберіть, чи перекладати звук з **мікрофона** чи з **системного аудіо (Loopback)**. Невелика бібліотека Loopback завантажується один раз під час першого використання з вашого дозволу.
- **Контекст:** Для режимів екрану та веб-камери виберіть функцію **що я роблю** (наприклад, перегляд фільму, участь у зустрічі чи дзвінку, читання етикетки або перевірка свого зовнішнього вигляду), щоб зосередити звітування; ви також можете ввести власний контекст.
- **Звітування:** Додаток порівнює кожен новий кадр із попереднім і надсилає його ШІ лише тоді, коли зображення дійсно змінилося, тому статичний екран ніколи не витрачає ваші запити. ШІ повідомляє лише про те, що є новим, і ніколи не повторюється.
- **Привітальне повідомлення:** За винятком режиму перекладу, спостерігач коротко вітає вас під час запуску, щоб ви знали, що він слухає.
- **Налаштування:** У розділі **Налаштування > Live помічник** встановіть **Режим спостерігача**, **Інтервал між кадрами** (від 1 до 10 секунд) та **Стиль звітування** (короткий або детальний). Інструкцію для спостерігача та текст кожного контексту можна редагувати в Менеджері підказок (розділ **Спостерігач**).

## ## 12. Користувацькі підказки та змінні

Ви можете керувати підказками в **Налаштуваннях > Підказки > Керування підказками...**.

- **Фільтр:** На вкладці **«Підказки початково»** над списком підказок розташований список **«Фільтр»**, який дозволяє показувати **«Усі»** підказки або лише один розділ за раз (наприклад, **«спостерігач»**), що полегшує навігацію по довгих списках.

### Налаштовувані комбінації клавіш для підказок

Призначте будь-якій налаштовуваній підказці власну комбінацію клавіш безпосередньо в «Менеджері підказок» і запускайте її миттєво з поточним вибором або в поточному контексті:

- **Одинарна клавіша** (наприклад, `1`, `p` або `F3`): працює всередині рівня команд, а також глобально як `NVDA + Shift + клавіша`.
- **Комбінація клавіш** (наприклад, `Control + Shift + 1`, `Alt + P` або `Insert + 1`): працює глобально самостійно.

### Поведінка зворотного зв’язку для кожного запиту

Для кожного користувацького запиту можна окремо визначити спосіб подачі відповіді:

- **Глобальне налаштування:** Дотримується загального налаштування виведення даних у Connection (Пряме виведення або вікно чату).
- **Копіювати до буфера обміну:** Копіює відповідь ШІ безпосередньо до буфера обміну без відкриття вікна.
- **Прямий вивід (повідомлення NVDA):** Промовляє або відтворює відповідь ШІ шрифтом Брайля безпосередньо через функцію озвучування NVDA.
- **Копіювання в буфер обміну та прямий вивід:** Копіює відповідь у буфер обміну та промовляє її безпосередньо.
- **Вікно чату:** Завжди відкриває результат у вікні інтерактивного діалогу.

### Доступні змінні

- `[selection]`: Поточний вибраний текст.
- `[text]`: Повний текст поля редагування у фокусі (автоматично ігнорує захищені поля для введення пароля).
- `[currentURL]`: URL веб-сторінки або документа з підтримуваних браузерів (Chrome, Edge, Firefox).
- `[clipboard]`: Вміст буфера обміну.
- `[clipboard_image]`: Зображення, яке наразі знаходиться у буфері обміну.
- `[screen_obj]`: Знімок екрана об’єкта навігатора.
- `[screen_fg_obj]`: Знімок екрана активного вікна на передньому плані.
- `[screen_full]`: Знімок екрана у повноекранному режимі.
- `[file_ocr]`: Вибрати зображення/PDF-файл для видобування тексту.
- `[file_read]`: Вибрати документ для читання (TXT, код, PDF).
- `[file_audio]`: Вибрати аудіофайл для аналізу (MP3, WAV, OGG).
- `[ambient_screen]`: Запускає безперервну фонову сесію спостерігача екрану.
- `[ambient_webcam]`: Запускає безперервну фонову сесію спостерігача Веб-камери  (перевіряє налаштування «Натисніть, щоб говорити»).
- `[ambient_audio]`: Запускає сеанс перекладу спостерігача аудіо у режимі реального часу.
- `[loopback]`: Використовує відтворення системного аудіо як джерело звуку (для `[ambient_audio]`).
- `[mic]`: Використовує мікрофон як джерело звуку (для `[ambient_audio]` та `[ambient_webcam]`).
- `[brief]`: Встановлює стиль звітування спостерігача як стислий (одне речення).
- `[detailed]`: Встановлює стиль звітування спостерігача як детальний (2–3 речення).
- `[lang:code]`: Вказує код мови перекладу аудіо (наприклад, `[lang:fa]`, `[lang:en]`).
- `{target_lang}`: Поточна мова перекладу.
- `{source_lang}`: Поточна мова оригіналу.
- `{response_lang}`: Поточна мова відповіді ШІ.
- `{swap_target}`: Запасна мова для перекладу за допомогою функції «smart swap».
- `{swap_instruction}`: Блок інструкцій для перекладу за допомогою функції «smart swap».

_Примітка щодо підказок з використанням змінних середовища:_ Підказки, що містять змінні середовища, діють як перемикач — натискання комбінації клавіш під час їхньої активності негайно припиняє сеанс. Несумісні комбінації (наприклад, поєднання статичних змінних знімків екрана, таких як `[screen_full]`, з режимами спостереження за середовищем, поєднання декількох режимів середовища або додавання інструкцій до підказки `[ambient_audio]`) піддаються суворій перевірці та блокуються під час збереження.

## ## 13. Реальні випадки використання (Яку функцію мені слід використовувати?)

Vision Assistant Pro оснащений безліччю сучасних інструментів. Ось кілька типових сценаріїв, які допоможуть вам вибрати потрібний:

- **Сценарій: Ви хочете зрозуміти повне розташування елементів у складному вікні або недоступній програмі.**

- **Сценарій: Ви переглядаєте на екрані відеоурок або анімацію без звуку.**

- **Сценарій: Ви зіткнулися з неочікуваною помилкою, збоєм API-з’єднання або хочете діагностувати проблеми з користувацькими локальними серверами.**
  _Рішення:_ Перейдіть до **Налаштування > Розширене**, поставте позначку **"Увімкнути спеціальний файл журналу"** та встановіть для **Рівень журналу** значення **"Налагодження"**. _Рішення:_ Перейдіть у розділ **Налаштування > Розширене**, встановіть прапорець **«Увімкнути окремий файл журналу»** та встановіть для параметра **Рівень журналу** значення **«Налагодження»**. Натисніть **G** у командному шарі (або скористайтеся пунктом **Отримати ключ API Gemini...** у налаштуваннях), увійдіть через свій браузер без жодних зовнішніх налаштувань, і ваш ключ буде створено та налаштовано після одного підтвердження — навіть якщо ви раніше ніколи не мали проєкту.
- **Спостерігач**: фоновий помічник уже доступний. Натисніть **Shift+O** у командному шарі, щоб запустити його, і натисніть ще раз, щоб зупинити. Він може перекладати те, що чує (через ваш мікрофон або системний звук), стежити за екраном і повідомляти про зміни, або відкривати Live помічника за допомогою вашої веб-камери та функції Натисніть, щоб говорити, щоб ви могли запитати про все, що бачить камера. Він надсилає зображення лише тоді, коли щось справді змінилося, тож нерухомий екран вам нічого не коштує, а коли нічого не відбувається, він мовчить. Ви також можете запускати та вмикати/вимикати спостерігача безпосередньо через «Користувацькі підказки» та спеціальні комбінації клавіш, використовуючи `[ambient_screen]`, `[ambient_webcam]` або `[ambient_audio]` разом із модифікаторами (`[loopback]`, `[mic]`, `[brief]`, `[detailed]`, `[lang:code]`), з автоматичною перевіркою на наявність конфліктуючих комбінацій змінних.
- **Live оператор**: Live помічник тепер може виконувати ваші запити на вашому комп’ютері, поки ви з ним розмовляєте. Натисніть **Control+A** у командному шарі, щоб розпочати сеанс Live оператора, а потім просто задавайте запити простою мовою. Він обробляє багатоетапні запити, озвучує кожен крок власним голосом Live помічника, самостійно натискає необхідні комбінації клавіш і самостійно визначає, коли завдання виконано. Функція **Прямий вивід (без вікна)** також доступна у «Швидких налаштуваннях».
- **Словник персонажів та керування серіалами**: діалог «Аналіз відео» тепер містить потужну систему **Словника персонажів**! Додавайте, редагуйте, імпортуйте або керуйте іменами персонажів, їхніми фізичними описами та ролями для кожного серіалу — ШІ автоматично зіставляє виявлених персонажів із вашим словником і додає нових у міру аналізу нових епізодів. Ваші ручні нотатки завжди зберігаються з пріоритетом над оновленнями ШІ, тоді як фізичні описи залишаються актуальними у всіх епізодах. Словник зберігається окремо для кожного серіалу та повторно використовується для кожного відео в цьому серіалі. У списку персонажів натисніть **F2**, щоб редагувати вибраного персонажа, та **Delete**, щоб видалити його.
- **Підтримка SOCKS5, HTTP та зворотного проксі з тестуванням затримки**: безперешкодно обходьте мережеві обмеження завдяки повній підтримці проксі в усьому додатку — включаючи Live помічника, спостерігача та генерацію TTS! Оберіть один із 4 режимів роботи в розділі «Загальні налаштування»: **Автовизначення**, **Проксі SOCKS5**, **Проксі HTTP** або **Зворотний проксі**. SOCKS5 підтримує аутентифікацію за ім’ям користувача та паролем згідно з RFC 1929, а також тунелювання доменів; проксі HTTP підтримує базову аутентифікацію. Нова кнопка **«Перевірити з’єднання з проксі»** працює у фоновому режимі та показує затримку з’єднання у мілісекундах.
- **48-годинне кешування відеофайлів**: відео, завантажені в Gemini, тепер кешуються протягом 48 годин! Ви можете повторно генерувати SRT- або MP3-файли для того самого відео без повторного завантаження — навіть після перезапуску NVDA. Кеш є чутливим до ключів і автоматично анулюється при зміні вашого API-ключа.
- **Виявлення тиші на основі  ШІ (Silero VAD)**: Розширений AD тепер використовує нейронну модель Silero VAD для точного виявлення тиші — розрізняючи природні паузи в діалозі від музики та фонового шуму. Модель завантажується автоматично під час першого використання (з вашого дозволу), так само як ffmpeg та eSpeak.
- **Відео з веб-камери для Live помічника**: У вікні Live помічника тепер є прапорець **«Використовувати веб-камеру»**, щоб надсилати ШІ зображення з веб-камери замість екрана — це ідеально підходить для запитань про фізичні об’єкти, документи або оточення. Якщо ffmpeg ще не встановлено, позначення прапорця завантажить його (одноразово, з вашого дозволу). Ця функція вимкнена, якщо камера не виявлена або налаштування конфіденційності Windows блокують доступ до камери; у такому разі з’являється кнопка для відкриття налаштувань конфіденційності камери. Якщо камера увімкнена, але не передає кадри, проблема фіксується в журналі NVDA для діагностики, замість того, щоб тихо перемикатися назад на екран.
- **Вибір пристрою для виведення звуку**: Тепер ви можете вибрати окремий пристрій виведення звуку для Live помічника та спостерігача. Обирайте між стандартним виведенням NVDA, Windows Sound Mapper або будь-якою підключеною фізичною звуковою картою (наприклад, USB-навушниками чи зовнішніми колонками) на вкладці «Налаштування Live», безпосередньо у діалозі Live помічника або на льоту за допомогою «Швидких налаштувань» (NVDA+Shift+V, потім стрілка вгору/вниз/вліво/вправо).
- **Менеджер підказок**: На вкладці «Початкові підказки » тепер є список **«Фільтр»**, тож ви можете показати всі підказки або лише один розділ (наприклад, **«спостерігач»**). Там також можна редагувати контекстні підказки спостерігача та нову **«Інструкцію Live оператора»**.
- **Розумна фільтрація моделей у розширеній маршрутизації**: Випадаюче меню «Розширена маршрутизація моделей» тепер динамічно класифікує моделі Gemini за можливостями, не перевантажуючи інтерфейс. «Live помічника» показує лише справжні двонаправлені моделі в режимі реального часу та моделі з нативним аудіо, «TTS» — лише спеціалізовані моделі синтезу мовлення, «STT» надає пріоритет моделям «Транскрибування» та мультимодальним моделям, а «Аналіз відео», «OCR» та «ШІ оператор» чітко відфільтровують одноцільові утилітарні моделі (такі як моделі генерації зображень, генерації відео). Майбутні моделі виявляються автоматично на основі можливостей без необхідності оновлення версій.
- **Відстеження першої появи персонажа**: ШІ тепер описує зовнішність кожного персонажа лише один раз — під час його першої появи у відео. Під час наступних появ використовуються лише імена, що усуває повторювані описи у різних сегментах, зберігаючи при цьому свіжість і природність розповіді.
- **Уніфікований каталог даних**: Усі файли даних додатка (історія, серіали, підписи, перебіг виконання OCR, кеші та журнали) було перенесено в єдину папку `VisionAssistant` у вашому каталозі налаштувань NVDA — це дозволяє підтримувати порядок і спрощує створення резервних копій вручну.
- **Покращений процес збереження відео**: під час збереження файлів SRT або MP3 діалог файлів тепер початково відкривається у папці вихідного відео, незалежно від того, чи відкриваєте ви відео через діалог файлів, чи за допомогою комбінації клавіш Shift+V у Провіднику.
- **Видалення документів із кешованим текстом або без нього**: діалог «Історія» (`Control + H`) тепер пропонує два способи видалення документа — натисніть клавішу Delete і виберіть **«Видалити лише з історії»** або **«Видалити з історії та кешованого тексту»**. Другий варіант очищає кешований текст OCR цього документа, тож під час наступного відкриття його буде перескановано з нуля — це ідеальний варіант після невдалого сканування. Прапорець **«Більше не запитувати»** запам’ятовує ваш вибір для майбутніх видалень. Дані про відновлення перерваної операції залишаються недоторканими.
- **Об’єднання кешу OCR у читачі документів з урахуванням механізму розпізнавання тексту**: Кешований текст OCR тепер зберігається для кожного механізму розпізнавання тексту, тому перемикання механізму розпізнавання тексту завжди призводить до повторного сканування з новим механізмом, а не до відтворення старого результату. Повторне відкриття документа знову показує діалог діапазону сторінок (попередньо заповнене вашим останнім вибором), миттєво повторно використовуючи вже відскановані сторінки та скануючи лише відсутні — кеш об’єднує сторінку за сторінкою, а не замінює її, тому кожен діапазон, який ви сканували, зберігається для подальшого використання.
- **Стиснення PDF-файлів у читачі документів**: У діалозі вибору діапазону сторінок читача документів додано опціональний параметр **«Стиснути сторінки PDF перед обробкою»**. Під час завантаження великих або відсканованих з високою роздільною здатністю PDF-документів у Gemini чи Mistral сторінки автоматично зменшуються та стискаються заново, що дозволяє значно зменшити розмір завантажуваних даних, пришвидшити обробку та запобігти перевищенню ліміту часу підключення до мережі. Ця функція початково вимкнена та автоматично приховується під час використання двигуна Chrome або постачальників зображень на основі base64.
