**Vision Assistant Pro** 是一款专为 NVDA 设计的高级多模态 AI 助手。它利用世界顶级的 AI 引擎提供智能屏幕阅读、翻译、语音听写和文档分析功能。它利用世界顶级的 AI 引擎提供智能屏幕阅读、翻译、语音听写和文档分析功能。

_本插件的发布旨在纪念国际残疾人日，以此回馈社区。_

## 1. 设置与配置

请前往 **NVDA 菜单 > 偏好设置 > 设置 > Vision Assistant Pro**。设置对话框分为 9 个无障碍标签页：**连接**、**实时助手**、**AI 行为**、**翻译语言**、**文档阅读器**、**视频**、**验证码**、**提示词** 和 **高级**。

### 1.1 连接选项卡

- **提供商：** 选择您首选的 AI 服务。**服务提供商：** 选择您偏好的 AI 服务。支持的提供商包括 **Google Gemini**、**OpenAI**、**Mistral**、**Groq**、**MiniMax** 和 **自定义**（兼容 OpenAI 的服务器，如 Ollama、LM Studio、Jan.ai 或 KoboldCPP）。
- **API 密钥：** 输入一个或多个 API 密钥（以逗号或换行符分隔），以便自动轮换使用。
- **获取模型：** 输入 API 密钥后点击此按钮，以从提供商下载最新的可用模型列表。
- **AI 模型：** 选择用于常规聊天和分析的主模型。
- **高级模型路由（特定任务）：** 可选地从下拉列表中为 OCR、STT、TTS、AI 操作员、视频和实时助手任务选择专用模型。对于 Gemini，模型会根据功能动态分类，界面整洁不杂乱。
- **Universal Local AI Integration (Setup Local AI)**: Added a new **"Setup Local AI"** button in Custom Provider Settings. Users can now automatically configure local AI engines, including **Ollama**, **LM Studio**, **Jan.ai**, and **KoboldCPP** instantly.
- **代理配置：** 全面支持整个插件（包括实时助手、环境观察者和 TTS）的网络代理与端点重定向。输入您的 **代理 URL** 并选择 **代理模式**：输入您的 **代理 URL** 并选择您的 **代理模式**：
  - **自动检测：** 自动检测 URL 是正向代理还是反向代理。
  - **SOCKS5 代理：** 强制通过 SOCKS5 进行隧道转发，支持 RFC 1929 用户名/密码身份验证及域名解析。
  - **HTTP 代理：** 强制通过标准 HTTP 代理进行隧道转发，支持基本身份验证。
  - **反向代理：** 直接替换 API 端点，适用于自建镜像和 AI 网关（在此模式下身份验证字段将自动禁用）。
- **测试代理连接：** 非阻塞按钮，用于测试连通性并通过 NVDA 朗读以毫秒为单位的服务器延迟。
- **连接与输出选项：** 配置启动时检查更新、聊天中清理 Markdown、将 AI 回复复制到剪贴板，以及直接输出（不打开聊天窗口）。
- **保存聊天记录：** 将您的聊天对话保存在历史记录列表中。

### 1.2 实时助手选项卡

- **实时助手：直接输出（无窗口）：** 启动实时助手且不显示其对话窗口；稍后可使用“重呼上次结果”按键（`空格键`）将其打开。
- **按键通话 (Push to Talk)：** 切换按键通话模式。启用后，麦克风仅在按住指定快捷键时发送音频。启用后，仅在按住指定按键时麦克风才会发送音频。
- **按键通话快捷键：** 按下按键以录制快捷键（例如 `F12` 或 `Ctrl+F12`）——您甚至可以分配单个修饰键（如 `左 Ctrl`）。按住按键说话，松开按键结束；每次按下和松开都会发出简短的提示音进行确认。

注意：该选项卡仅在当前活动提供商为 **Google Gemini**（或兼容 Gemini 的自定义提供商）时可见。

### 1.3 AI 行为选项卡

- **创意度 (Temperature)：** 控制 AI 的随机性和创意度（从 0.0 到 2.0）。较低的值在翻译和 OCR 任务中会产生更确定、更准确的结果。较低的值会产生更确定和准确的翻译/OCR 结果。

### 1.4 翻译语言选项卡

- **源语言：** 选择您的默认输入语言。
- **目标语言：** 选择您的主要目标翻译语言。
- **AI 回复语言：** 选择 AI 进行通用回复时使用的语言。
- **智能互换 (Smart Swap)：** 根据检测到的输入文本语言，自动互换源语言和目标语言。

### 1.5 文档阅读器选项卡

- **OCR 引擎：** 在 **Chrome（快速）**（适合快速查看）和 **AI（高级）**（适合完美保留排版和复杂布局）之间进行选择。
- **OCR 批处理大小：** 指定每次请求处理的页数（设为 0 则在单次请求中处理整个文件）。
- **内联描述图像：** 在文档文本提取过程中，自动对文档中的图像进行内联描述。
- **导出页码：** 在多页文档的输出结果中添加页码和分隔符。
- **TTS 语音：** 选择朗读音频生成时使用的默认声音风格。
- **保存文档到历史记录：** 在历史记录列表中保留已打开的文档；已缓存的 OCR 文本和继续进度数据依然会被保存。

### 1.6 视频选项卡

- **视频分块大小：** 生成音频旁白描述时的分段时长（以分钟为单位；设为 0 则整体处理整个文件）。
- **添加角色列表：** 选择是否将角色词典作为字幕文件的第一条内容。
- **添加 AI 声明：** 选择是否在视频 SRT 字幕开头插入 AI 免责声明。
- **角色词典与剧集管理：** 为每个剧集添加、编辑、导入或管理角色名称、外貌特征和身份角色 — AI 会自动将识别出的角色与词典进行匹配，并在您分析更多剧集时自动合并新角色。您的手动备注始终优先于 AI 更新，且外貌描述会在所有剧集中保持最新。您手动添加的备注始终优先保留，不会被 AI 更新覆盖，而外貌特征描述则会在各剧集之间保持最新状态。

### 1.7 验证码标签页

- **启用视觉验证码解析器：** 自动识别并解析视觉人机挑战（hCaptcha 和 reCAPTCHA）。
- **文本验证码捕获方式：** 在捕获 **导航对象** 或 **全屏** 之间选择。

### 1.8 提示词选项卡

- **管理提示词：** 打开专用管理窗口，用于自定义默认系统提示词，或使用动态变量（如 `[selection]`、`[screen_fg_obj]`、`[currentURL]`、`[text]`）创建、编辑、排序和预览自定义提示词。
- **自定义提示词快捷键：** 直接在提示词管理器中为任意自定义提示词分配专用快捷键。按下按键即可录制——单个按键在命令层内运行（并在全局作为 `NVDA + Shift + 按键` 运行），而类似 `Control + Shift + 1` 的组合键则在全局独立运行。
- **各提示词独立反馈行为：** 分别为每个提示词单独选择输出结果的方式（全局设置、复制到剪贴板、直接输出 / NVDA 消息、复制到剪贴板 + 直接输出，或聊天窗口）。

### 1.9 高级选项卡与全局日志

切换到 **高级** 选项卡以配置全局日志功能：

- **启用独立日志文件：** 将插件所有模块的操作事件、API 交互流量和错误单独记录到一个独立文件中 (`vision_assistant.log`)。
- **日志级别：** 在 **调试（所有详细信息）**、**信息（常规信息）**、**警告（仅限警告）** 和 **错误（仅限错误）** 之间选择记录详细程度。
- **日志保留时长：** 设置自动清理旧日志的时间周期（从 1 小时到 90 天不等）。
- **日志管理控制：** 点击 **打开日志文件**、**打开日志文件夹** 或 **清空日志文件**，无需重启 NVDA 即可直接检查或清空日志。
- **统一数据目录：** 插件的所有数据文件（历史记录、剧集、标签、OCR 进度、缓存和日志）均整合存放在 NVDA 配置目录下的单个 `VisionAssistant` 文件夹中，使数据管理和手动备份变得极其轻松。

### 1.10 设置备份与恢复

**高级** 选项卡中还包含了 **备份与恢复** 区域：

- **备份：** 将您的完整配置保存为一个单独的 JSON 文件。点击后可选择备份内容：**全部内容**（包含设置、自定义标签、OCR 进度和历史记录）或 **仅设置**。点击时，您可以选择要包含的内容：**所有内容**（设置、自定义标签、OCR 进度和历史记录）或 **仅设置**。
- **恢复：** 随时在任何电脑上或重新安装 NVDA 后载入先前的备份文件以恢复配置和数据。恢复前会要求您确认，因为恢复将完全替换现有的设置和数据。系统会先要求您确认，因为还原操作会替换您当前的所有设置和数据。

## 2. Gemini API 密钥管理器

**重磅改进 — Gemini API 密钥创建终于变得轻松：** 过去在 **aistudio.google.com** 获取密钥是最繁琐的步骤。如今直接在命令层中按下 **G**，通过默认浏览器登录即可一键完成创建与绑定。使用读屏软件时网页操作令人困惑，部分用户甚至根本无法创建密钥。 **Gemini API 密钥管理器** 解决了这一问题。在命令层中按 **G**，或打开 **NVDA 菜单 > 偏好设置 > 设置 > Vision Assistant > 连接** 并按 **获取 Gemini API 密钥...**。

- **登录：** 打开管理器时，系统会直接在默认浏览器中打开 Google 的安全登录页面。使用您的 Google 账号登录——无需安装任何外部工具、SDK 或进行命令行配置。您当前登录的账号始终会显示在 **退出登录** 按钮上。
- **创建密钥：** 登录后，您可以使用 **新建项目和密钥** 立即创建密钥，无需任何前期配置。如果您已有现存项目，它们会显示在一个简洁的列表中，您可以选择一个项目并按 **为选定项目创建密钥**。
- **后续流程：** 新密钥会立即复制到剪贴板，保存在插件中备用，并且系统会询问一次是否将其添加到插件的密钥列表中。仅需这些操作——无需在网页中反复搜寻。
- **管理您的密钥：** **复制选定项目的密钥** 会复制您所选项目的密钥，**复制最后创建的密钥** 会复制您刚才创建的密钥，而 **导出已保存的密钥到 CSV...** 则会将您创建的所有密钥保存到文件中。
- **删除密钥：** **删除密钥...** 会显示所选项目中存在的密钥，询问您要移除哪一个，并在删除前要求确认。删除密钥还会将其从插件的密钥列表中移除，确保轮换中绝不会遗留失效的密钥。只要您的账号在该项目中拥有权限，在插件外部创建的密钥也同样可以删除。
- **退出登录：** **退出登录** 会从您的计算机中清除已存储的登录信息，方便您随时切换到其他账号。

## 4. 聊天与历史记录

聊天窗口与历史记录管理器深度协同运作，让您能够随时温习过往的对话并无缝继续此前的工作。

### 3.1 聊天窗口快捷键

当聊天窗口打开时（包括直接聊天、文档问答、文本润色等场景），您可以使用以下快捷键进行高效交互：

- **Alt + 向下键：** 阅读下一条消息。
- **Alt + 向上键：** 阅读上一条消息。
- **Alt + C：** 复制当前消息。

### 3.2 历史记录 (Control + H)

在命令层中按 **Control + H** 打开 **历史记录** 对话框，查看您过去的聊天和文档，可按类型进行筛选（全部 / 聊天 / 文档）。打开某次聊天以继续对话——包括其附加文件，这些文件会自动重新附加——或打开某篇文档继续阅读。在任意项目上按 **Delete** 键将其移除，或按 **全部清除** 清空列表。对于文档，按 Delete 键会询问您是仅从历史记录中移除条目，还是同时清除该文档缓存的 OCR 文本（以便下次打开时从头重新扫描）——并提供 **不再询问** 选项以记住您的选择。

您还可以选择列表中记忆的内容。**保存聊天到历史记录**（连接标签页）和 **保存文档到历史记录**（文档阅读器标签页）默认均处于开启状态，并且都可以在快速设置中进行切换。文档选项仅影响历史记录条目——缓存的 OCR 文本和恢复进度数据始终会被保留。

## 5. AI 操作员 - 自主计算机控制

**AI 操作员** 将 Vision Assistant Pro 从被动阅读器转变为可以代表您与计算机交互的主动助手。您可以要求它描述屏幕、回答关于所见内容的问题，甚至接管控制——使用自然语言指令点击按钮、拖动项目、输入文本并在应用程序中导航。您可以让它描述屏幕、回答有关所见内容的问题，甚至接管控制——通过自然语言命令点击按钮、拖拽项目、键入文本以及在应用程序间穿梭导航。

最大的优势是什么？它在完全无障碍缺失的软件中也能完美运行。如果您受困于某个自定义应用程序、远程桌面或导致读屏软件完全沉寂的网站，操作员也能应对自如。因为它从视觉上“看到”屏幕，所以能够查找、读取完全没有无障碍标签的元素并与之交互。

### 4.1 工作原理

1. 按 **NVDA + Shift + V**，然后按 **Shift + A**（或使用直接快捷键）打开 AI 操作员对话框。
2. 用平实自然语言输入您想做的事情（例如，“点击保存按钮”、“错误信息说了什么？”，或“将文件重命名为 final.pdf”）。
3. AI 将分析您的屏幕，识别相关元素，并执行操作或提供答案。如果任务需要多个步骤，操作员将持续工作直到完成。如果一项任务需要多个步骤，操作员将持续工作直至全部完成。
4. 任何时候再次按 **Shift + A** 都可以立即中止正在进行的操作。

### 4.2 支持的操作

操作员理解广泛的命令：

- **描述与回答**：“描述屏幕布局” 或 “错误信息说了什么？”

- **右键点击**：“右键点击文件”

- **滚动**：“向下滚动三次”
- **按键**：“按 Enter”、“按 Tab”、“按 Escape”
- **多步骤任务**：“打开文件资源管理器，找到报告，并将其重命名为 final.pdf”

## 6. 视频分析与旁白描述

> **注意：** 视频分析和旁白描述功能严格由 **Google Gemini** 提供商驱动。请确保插件设置中您的活动提供商设置为 Google Gemini。请确保插件设置中的活动提供商已设为 Google Gemini。

Vision Assistant Pro 引入了专为视障用户设计的强大视频处理功能。它可以分析在线视频和本地屏幕录像，提供高度详细的视觉描述，并生成专业的旁白描述脚本 (SRT)。它可以分析在线视频和本地屏幕录像，提供高度细致的视觉描述并生成专业的口述影像脚本（SRT）。

### 5.1 本地屏幕录制 (Control + V)

如果您在屏幕上遇到无声视频、动画或教程，您可以直接捕获它：

1. 按 **NVDA + Shift + V** 进入命令层，然后按 **Control + V**。
2. 插件将在后台静音录制您的屏幕。
3. 再次按 **Control + V** 停止录制。
4. AI 随后将分析录制的视频片段，并对场景、角色和操作提供高度详细的描述。

### 5.2 视频分析 (Shift + V)

您可以分析本地视频文件和在线视频。您可以分析本地视频文件和在线视频。只需在 Windows 文件资源管理器中选中本地视频文件，或将在线视频链接复制到剪贴板。您也可以在任何地方（例如媒体播放器内部）按 **Shift + V** 打开对话框，手动浏览视频文件或粘贴 URL。您还可以在任意位置（例如媒体播放器内）按 **Shift + V** 打开一个对话框，在其中浏览视频文件或手动粘贴 URL。

- **支持的在线平台：** YouTube, Instagram, TikTok, 和 Twitter (X)。
- AI 将自动检测本地文件或 URL，处理视频，并提供全面的视觉描述和音频总结。
- **48小时视频文件缓存：** 上传到 Gemini 的视频缓存延长至 48 小时，重新生成字幕或配音无需重复上传。对于同一视频，无需重新上传即可重新生成 SRT 或 MP3 输出——即使重启 NVDA 后也是如此。缓存与密钥关联，当您的 API 密钥更改时会自动失效。

### 5.3 旁白描述生成 (SRT)

为了获得更有条理的体验，插件可以生成标准 SubRip (SRT) 格式的专业旁白描述脚本。

- **智能间隙对齐：** AI 会监听音频轨道，并将视觉描述专门锚定到自然停顿和静音间隙，以明智地减少与原声对话的重叠。
- **角色追踪：** 引擎执行预处理 pass，根据面部特征提取不同的角色。它构建了一个全局字典，以便在不同场景之间准确跟踪和标注角色而不会混淆。它会构建一个全局词典，在不同场景间准确追踪并标记人物角色，避免混淆。它还会记录每位角色的 **首次登场**，仅在他们初次出现时描述一次外貌特征，在后续场景中则仅使用已确立的角色姓名，从而保持旁白叙述的精炼与自然。
- **逐字文本 OCR：** 屏幕上出现的任何文本（标志、手机、字幕）都会被严格逐字引用。
- **如何使用：** 要听取生成的字幕，只需将 `.srt` 文件放在与视频文件相同的文件夹中，并给它赋予完全相同的名称。然后配置您的媒体播放器（如 VLC 或 PotPlayer）在播放期间将字幕文本直接发送到您的屏幕阅读器或 TTS 引擎。然后，配置您的媒体播放器（例如 VLC 或 PotPlayer），在播放期间将字幕文本直接发送给读屏软件或 TTS 引擎。
- **Alt + G：** 生成并保存高质量音频文件 (WAV/MP3)。_(如果提供商不支持 TTS 则隐藏)_。

### 5.4 同步音频旁白导出 (MP3)

除了生成纯文本 SRT 文件外，该插件还可将描述内容合成为语音并将其混入视频中，从而作为一个完整的口述影像制作工具使用。您现在可以选择 **Gemini Live TTS** 作为语音引擎，它利用 Gemini Live API 生成高度逼真且无字数限制的语音旁白。为本地视频文件生成 MP3 时，您可以使用多种混音模式：

- **标准口述影像（混合语音）：** 旁白语音直接叠加在视频的原音频之上。系统会提示您是否应用 **音频避让**（在描述期间降低背景音量），以确保旁白清晰可辨。
- **扩展旁白 (暂停原声)：** 引擎在旁白描述期间暂停原始视频音频，确保您不会错过原始对话或 AI 旁白的任何一个字。静音检测现采用 **Silero VAD** 神经网络模型（首次使用时会自动下载，正如 ffmpeg 和 eSpeak 一样）以实现精确的间隙计时——将自然的对话停顿与音乐和背景噪音区分开来。
- **YouTube 视频：** 对于 YouTube 来源（未在本地下载），导出的 MP3 将严格仅包含同步的 AI 语音轨道，而不包含背景视频音频。

## 8) 高级文档与图像阅读器

**文档阅读器** 可将您的文档转换为清晰易读的文本——让您可以阅读、翻译并聆听从扫描书籍到一叠照片的任何内容。它支持多页 PDF、复杂图像、iPhone HEIC 格式，甚至是纯文本（`.txt`）和 HTML（`.html`、`.htm`）文件，这些文件无需 OCR 或 AI 处理即可瞬间打开。一次性选择多个文件，它们将按页面顺序合并为一份连续的文档。提供三种 OCR 引擎可供选择——**Chrome (快速)**、具有卓越版面保留能力的 **AI (高级)**，以及用于可搜索 PDF 的 **无 (提取文本层)**——可在 设置 → 文档阅读器 中选择。

### 工作原理

1. 按 **NVDA + Shift + V**，然后按 **D** 打开文档阅读器——或者先在文件资源管理器中选中文件，然后按 **D** / **F** 直接跳过文件对话框。
2. 选取一个或多个 PDF 或图像。插件会对其进行扫描并播报总页数。
3. 在 **选项** 对话框中，选择页面范围（从/到）。您还可以勾选 **翻译输出** 并选择目标语言，切换 **在 OCR 期间行内描述图像**，或切换 **处理前压缩 PDF 页面** 以便在上传前对过大的扫描页面进行降采样并重新压缩。
4. 文本提取将在后台分批开始。您可以随时关闭窗口并在稍后继续——内容绝不会丢失。
5. 页面准备就绪后，即可在查看器中进行阅读：在页面间移动、跳转到任意页面、向 AI 提问、保存文本或生成语音旁白。

### 7.1 批量处理与恢复

您无需一次性读完大篇幅文档。选择页面范围（例如 `1-20`）或保留默认设置以处理全部内容，AI 将在后台提取所有页面。如果 NVDA 崩溃或您中断了扫描，插件会记住您的进度并提示 **恢复** 到上次中断的确切位置——即使重启后也是如此。已完成的文档也会被缓存，因此重新打开它们（从“最近打开的文档”或按 **D** 打开）将立即加载文本而无需重新运行 OCR，除非源文件已发生更改。

### 7.2 智能文件操作

您并不总是需要先打开文档。在 Windows 文件资源管理器中，只需选中 PDF、图像或文本/HTML 文件，然后在命令层内按 **D**（文档阅读器）——或选中 PDF、图像并按 **F**（智能文件操作）即可。插件会立即跳过文件对话框并开始处理所选文件。一次选择多个文件会将其合并为一份文档一并处理。

### 7.3 文档查看器控制与快捷键

在文档阅读器窗口打开时，您可以使用以下快捷键：

#### 键盘快捷键

- **Ctrl + PageDown / Ctrl + PageUp：** 移至下一页 / 上一页。
- **向下 / 向上箭头键：** 当光标到达页面的最后一行时，按 **向下键** 跳转到下一页；在页面顶部按 **向上键** 返回上一页。
- **Alt + A：** 打开聊天对话框以针对文档内容提问。
- **Alt + R：** 强制使用您的活动提供商 **使用 AI 重新扫描**。
- **Alt + G：** 生成并保存高质量音频文件（WAV/MP3）。_（若提供商不支持 TTS 则隐藏）。_
- **Alt + S / Ctrl + S：** 将提取的文本保存为 TXT 或 HTML 文件。

#### 按钮与控件

- **转到：** 从页面选择器中选取任意页面。
- **查看格式化内容：** 查看整篇文档合并后的格式化文本。
- **重试失败页面：** 仅重试由于临时服务器错误（例如高并发需求）而失败的批次。此按钮在需要时会自动显示。
- **TTS 语音 / TTS 引擎：** 选择语音，若使用 Gemini，可在 **标准 TTS** 和 **Gemini Live** 流式传输之间选择。
- **上一页 / 下一页：** 在页面之间切换（与 Ctrl+PageUp/Down 快捷键相同）。

### 7.4 最近文档 (D)

在命令层中按 **D** 会首先列出您最近阅读的文档。选择其中一项可从您上次停留的页面继续阅读——即使 OCR 已经完成也是如此——或者按 **打开文件...**（`Ctrl + O`）照常浏览文件。

- **设置：** 在 **设置 > 实时助手** 中，设置 **观察者模式**、**帧间隔**（1 到 10 秒）以及 **报告风格**（简短或详细）。观察者指令和各个上下文文本均可在提示词管理器中进行编辑（**环境** 部分）。
